楼道电台

给每一盏声控灯配一个频道。夜里有人经过，灯亮，只播这一层住户拾过的歌。

每层一个频道，频道名就是你给那盏灯起的名字。歌单来自住户自己愿意公开的穗。

第一步可以很小：先只做你家这一层，用一个蓝牙音箱和一张纸条。

可以先做的三件事
01 晚上上楼时，记下三楼那盏灯是第几声脚步亮起的，给它起个代号写在便签上。
02 挑一首只有钢琴与白噪音的歌，放进门边常驻的微型蓝牙设备，设为感应播放。
03 在开关盒旁贴一张名片大小的纸，留一行字：「三楼电台，今晚播 Bon Iver」。
