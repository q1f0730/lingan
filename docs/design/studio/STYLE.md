# 拾穗 · Glean — Studio 视觉规范

来源：Stitch 参考项目 7843834577505286568（建筑工作室作品集，7 屏 HTML 的 tailwind config 与 class 统计）+ 本轮 Glean · Studio 稿（Stitch 项目 1519444922065811289）。
一句话：**白纸黑字的编辑部目录**。内容（照片、文字）就是装饰，界面本身只剩字号、留白和一条线。

---

## 1. 原则（违反任何一条就是跑偏）

1. 只有黑、白、灰。没有品牌色、没有强调色。唯一的"色彩"来自用户自己的照片。
2. 0 圆角、0 阴影、0 描边卡片、0 图标装饰（导航纯文字，不加 icon）。
3. 层级只靠两件事：**字号反差**（巨型标题 vs 10–12px 小字）和 **留白**。
4. 线条极省：表格只在表头下有一条 1px 黑线，行与行之间不画线（参考 "Tight Table / No Line"）。
5. 不出现任何假统计、百分比、图表、徽章。唯一的数字：计数 `(10)`、日期、序号 `01/02/03`。计数必须等于真实条数。
6. 署名只用 `Q1f730`。无 emoji。界面文案简体中文，拉丁字母只有 `GLEAN`、链接域名、作品原名。

## 2. 字体

| 用途 | 拉丁/数字 | 中文配字 | 备注 |
|---|---|---|---|
| 全部 UI | **Inter** 400/500/600 | **Noto Sans SC / 思源黑体** 400/500/700 | 栈：`"Inter","Noto Sans SC","PingFang SC","Microsoft YaHei",sans-serif` |
| 宣言大字（Manifesto） | Inter 700/800（参考用 Epilogue 800，可选） | 思源黑体 700/900 | 强调词改用 **300 细体**，不用颜色、不用斜体（中文无真斜体） |
| 链接域名 | Inter 400 | — | 稿子里出现了等宽体（`radio.garden`、页脚 `Q1F730`），**实现时统一改回 Inter**，不引入第三种字体 |

- 中文不加字距（letter-spacing 0）；只有拉丁大写小字加宽字距。
- 中文标点用全角；书名统一加书名号：《一一》《完美的日子》（`一一` 不加书名号会被读成破折号，已踩坑）。

## 4. 间距与网格

- 基础单位 **10px**（参考 `base-unit: 10px`；nav 内边距 10px、图片间距 10px）。
- 页边距：移动 **16px**（参考移动 10px，中文需要多一点呼吸）/ 桌面 **40px**（参考 `edge-margin: 40px`）。
- 栅格：桌面 12 列、gutter 16px、最大宽 1800px；移动 4 列。
- 图片网格：移动 2 列、桌面 3 列，**间距 10px**，图块比例 **4:5**。
- 区块间距：顶栏到大标题 **120–160px**（桌面；参考 `section-gap 120/160`）、移动 64–80px；大标题到内容 10–24px；新枝之间 64px。
- 表格行高：移动 44px、桌面 64–72px（参考 `py-6`）；表头与第一行 16px。
- 列表列宽（移动 390）：穗 ~45% / 类型 15% / 来源 25% / 日期 15% 右对齐；桌面：穗 5/12、类型 2/12、来源 3/12、标签 1/12、日期 1/12。长标题单行省略。

## 5. 色值

### 白主题（默认）
| Token | 值 | 用途 |
|---|---|---|
| `bg` | `#FFFFFF` | 页面 |
| `fg` | `#000000` | 标题、正文、激活态、表头线 |
| `fg-2` | `#7E7E7E` | 次要列、meta |
| `fg-3` | `#C6C6C6` | 未激活切换、禁用、「不要」 |
| `tile` | `#F3F3F3` | 纯文字穗（摘抄/想法/链接）的图块底 |
| `hair` | `#E2E2E2` | 仅速记栏与导航之间的分隔（如需） |
| `scrim` | `linear-gradient(to top, rgba(0,0,0,.6), transparent 55%)` | 照片说明压暗，唯一允许的渐变 |

### 黑主题（Manifesto、夜间）
| Token | 值 |
|---|---|
| `bg` | `#000000`（参考面层 `#131313` 可用于二级面） |

## 6. 组件规则

**顶栏**：左 logo「拾穗 · GLEAN」20/600；桌面中间 5 个导航小字（穗仓 嫁接 新枝 口味 设置），激活项黑色 + 1px 下划线（offset 6px），其余灰；桌面右侧是速记输入（见下）。移动顶栏只放 logo + 右侧「设置」小字。

**速记「随手拾一穗」（常驻）**
- 移动：固定在底部导航上方，整宽，上方 1px 黑线，无框无底色，左 placeholder「随手拾一穗」15px 灰，右侧黑色小字按钮「拾」。
- 桌面：在顶栏右侧，宽 320px，只有一条 1px 下划线，placeholder「随手拾一穗 →」。**桌面不得再出现底部固定栏**（Stitch 稿第一版出现过，已删）。
- 聚焦时下划线变 2px，不弹浮层；回车即存，存完 placeholder 处淡入「已拾」1.2s。

**底部导航（移动）**：5 个纯文字 12px，等分；激活黑色 + 下划线，其余灰。**不加图标**（Stitch 编辑时自动加过一次图标，已改回）。

**大标题 + 计数**：`穗仓 (10)`，计数与标题同字号同字重，不变灰。右侧/下方是切换「网格 | 列表」：label 字号，激活黑、未激活 `fg-3`，中间竖线 `|` 用 `fg-3`；列表激活时加下划线。

**主按钮**：仅一种——黑底白字直角矩形，label 字号，padding 8×12（如「嫁接所选」）。其他动作一律是文字按钮：「留下」黑、「再接一次」灰、「不要」浅灰，间距 24px。

**图片穗（Grid）**：满铺 4:5，`object-fit: cover`，底部 scrim，左下角 16px 内边距：标题 16/600 白 + meta 12/400 白 80%（`照片 · 10/21`）。长标题单行省略。

**文字穗（Grid）**：同尺寸 `tile` 色块，左上 20px 内边距放正文（摘抄带引号，18/500 黑），左下放来源（12 灰）+ meta（12 黑）。链接穗在标题下放域名 12px 灰。

**表格（List）**：表头 10–12px 灰、单条 1px 黑线；行间无线；标题列黑，其余列 `fg-2`；日期右对齐、等宽数字（`font-variant-numeric: tabular-nums`）。桌面 hover：行标题右移 16px + 光标旁淡入 240×320 预览图（参考的交互）。

**新枝块**：细体序号 01 → 24/600 标题 → 15/400 一句话 → `因为这几穗`（label 灰）+ 来源穗名（12 黑，用 ` / ` 分隔，可点回原穗）→ 文字动作。每次嫁接固定 3 根。

**Manifesto（新枝大字视图）**：黑主题，内容居中，最大宽 1000px；`新枝 01 / 03` label → 宣言大字（强调词用细体）→ 因为这几穗 → 动作；底部 1px `hair` 线、左 `© 2026 Q1f730`、右 `01 02 03` 页码（当前项下划线）。

**口味页**：大标题「口味」→ 一句 lead 判断 → 两列无线表格「倾向 / 来自这些穗」，每行下方一行灰色小字控制「多一点 少一点 这不是我」→ 小节「最近冷下来的」。不出现任何分数、比例、雷达图。

**Spatial Archive（可选第三视图）**：参考里的散落拼贴——照片按不同比例（1:1、4:5、16:9、3:4）随机散落在白底上，右侧细小索引列表；可作为穗仓的"漫游"视图，后续再出稿。

**页脚**：10px 大写字距 0.1em，`© 2026 Q1f730`。

## 7. 动效（克制）

只允许两种：
1. **淡入**：元素进入视口 `opacity 0→1` + `translateY(8px→0)`，`400ms cubic-bezier(.2,0,0,1)`；列表/网格逐项错开 40ms，最多错开 8 项。
2. **图片缓慢放大**：hover（桌面）或长按（移动）时 `transform: scale(1.03)`，`700ms ease-out`；容器 `overflow:hidden`。参考用的是 `scale-105 / 500ms`，这里更慢更小。

其他：导航/切换只做 150ms 颜色过渡；不用弹簧、不用视差、不用骨架闪烁、不用页面转场滑动。

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation: none !important; transition: none !important; }
  img { transform: none !important; }
}
```
reduced-motion 下内容直接出现，hover 放大关闭，列表 hover 预览图直接显示不淡入。
