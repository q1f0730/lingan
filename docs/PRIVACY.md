# 拾穗 · Glean 隐私承诺（每条都有测试）

v0.43 起（0935）：这里每一条承诺都对应至少一个自动测试，测试名写在条目末尾。`src/__tests__/v043.test.ts` 会逐条核对这些测试真实存在（在 `e2e/run.mjs` 或 `src/__tests__/*.test.ts` 里），删了测试或改了名字，CI 直接失败。改承诺要同时改测试。

- **P1** 新装、打开、逛一遍各页：不向任何非本机地址发请求（字体、脚本、模型都在包里；本机小模型、AI、同步、订阅都要你自己打开）。测试：`[v043] external request`
- **P2** AI 服务的密钥只存在系统钥匙串里，不写进设置。测试：`保存新 key 只进钥匙串`
- **P3** 备份、诊断信息、错误日志里没有密钥。测试：`导出备份不含 key` / `诊断文本：有版本 / 平台 / 条数 / 最近错误，不含 key`
- **P4** 标成「私密」的穗永远不发给云端模型；只有你允许时才给本机模型看。测试：`云端永远不发；本地模型且允许时才发`
- **P5** 上锁的穗：任何模型都不发、Agent / MCP 看不到、不进每日一穗、花园和分享。测试：`上锁的穗：任何模型都不发、Agent 看不到、不进每日一穗 / 花园 / 分享溯源`
- **P6** 每一穗可以单独关掉出口（AI / Agent / 分享 / 花园），关掉的出口拿不到这一穗。测试：`关掉的出口拿不到这一穗，别的出口照常；上锁 = 全关`
- **P7** 接入可以一键停用；停用后对应的请求在发出前就被拦下。测试：`停用 AI 服务：模型调用直接拒绝，不发请求` / `blocks remote, allows local, default open`
- **P8** 分享出去的卡片不带「为什么」原文、不带私密穗，署名 Q1f730。测试：`导出卡 ≤300 字、署 Q1f730、不含私密穗、不含为什么原文`
- **P9** 同步数据在本机加密后才上传，口令错了解不开，挪了位置也解不开。测试：`口令 / 恢复码都能解开数据钥；错的解不开；换口令后旧口令失效` / `密文绑定路径：挪了地方解不开；改一个字节解不开`
- **P10** 收进来的照片会抹掉位置（GPS）和 XMP，拍摄时间只留作「拾于」候选。测试：`cleanJpeg('in')：GPS 数值清零`
- **P11** 照片离开本机（发给看图模型、导出到 Obsidian）前去掉 EXIF / GPS / 相机型号，只留方向（设置里可关）。测试：`cleanJpeg('out')：只留方向的最小 EXIF`
- **P12** 检查新版每天最多一次，可以关；关了就不查。测试：`每天最多一次；关掉就不查；时钟倒退也能恢复`

不承诺的事（写清楚）：上锁不是加密（拿到已解锁设备、或改系统时间的人能绕过冷静期）；备份文件 .glean 是原样的你的数据（含照片原有的 EXIF），自己保管好。
