## 拾穗 · Glean v0.29.0 — 创作产出

这一版让新枝能真的长成东西：任意一根新枝下点「立项」，选一个形态（短篇 / 短片 / 歌单 / 影评 / 海报 / 播客），它和来源穗一起变成一件作品，有自己的工作区——草稿、待办、素材，短片多一张分镜表，歌单只用你库里的歌排好起-落-起，海报和短片有一块能随便摆的情绪板。没有 AI key 也能用：每个形态都有现成的离线骨架，提示语直接引用你的穗。底部导航多了「作品」。

**下载**：安卓 `Glean_0.29.0_android.apk` · Windows `Glean_0.29.0_x64-setup.exe`（或 `.msi`）· Agent 桥 / 命令行 `glean-mcp.mjs` · 校验 `SHA256SUMS.txt`

**升级**：Windows 装着 v0.25 – v0.28 的会自动收到（更新前先自动备份）；安卓 v0.26 起可以在 设置 → 更新 里直接「下载并安装」。数据库升到 **Dexie v11**：只新增一张 `works`（作品）表，不动任何旧数据；升级前照例自动存一份原样副本。作品里引用的穗 / 新枝都存全局 uid，备份导到别的设备、操作前快照恢复后引用都不断。

**做了哪些（13 条，编号见 docs/ideas/ideas.csv）**

立项与工作区
- **0301 作品工坊**：新枝卡片多一个「立项」，选形态后建一件作品并直接打开（这根新枝顺手标成「留下」）。作品页有标题（点了就能改）、进度（构思 / 在做 / 完成）、待办、素材，列表按进度筛；也能不从新枝出发「空白作品」。删除走墓碑，可撤销
- **0302 形态模板**：六种形态各有自己的工作区结构——短篇：稿；短片：分镜 + 稿 + 情绪板；歌单：歌单 + 稿（串词）；影评：稿；海报：情绪板 + 稿；播客：稿 + 歌单。每种带三条「最小可交付」待办
- **0340 离线骨架**：立项时按形态生成章节和提示语，提示语直接引用素材穗（「从《重庆森林》里找一个具体的人」），不调用任何模型
- **0309 素材抽屉**：电脑上右侧常驻一栏素材（手机是「素材」页签）：从穗仓搜一穗加进来、移除、点标题看详情；「引用」把它插进草稿光标处，也可以直接拖进草稿

写
- **0303 写作编辑器**：Markdown 草稿（# 标题、- 列表、> 引用、**粗体**），打 `[[` 弹出穗选择器（先列素材，再列穗仓），回车插入引用；「预览」里引用变成可点的穗，点了回到那一穗；不是素材的穗被引用时自动加进素材。停手 0.4 秒自动保存。字数实时显示，撞到套路墙上的词会提示
- **0314 短篇五格**：短篇骨架 = 人物 / 欲望 / 阻碍 / 转折 / 结尾意象，结尾意象优先取图穗
- **0307 影评骨架**：立场 / 论点一二三 / 反驳 / 结尾，三个论点按「这部电影本身 → 同导演或同标签的穗 → 截图」各配一穗当证据，立场提示里带上你收它时写的为什么；目标 800 字，哪个论点没引用你的收藏会被点名

短片
- **0304 文字分镜表**：镜号 / 景别 / 画面 / 声音 / 时长，可增删、上下移；立项时按素材起一版（每穗一个镜头）。合计时长对目标时长，超了标红并说超出多少
- **0305 穗图当分镜帧**：每个镜头点左边的格子，从穗仓的图里选一张参考帧（素材里的排前面）；没选时显示景别字印（远 / 全 / 中 / 近 / 特）

歌单与情绪板
- **0306 灵感歌单**：只用库里的音乐穗（不碰反口味），先挑和素材同标签 / 同歌手的；按标题 / 为什么 / 标签里的词粗估能量，排成「开头中高、中间落下、结尾再起来」；每首一句「为什么在这」（开场 / 往下落 / 最低处 / 再起来 / 收尾 + 你当时写的为什么），可改、可排、可重排
- **0322 导出到音乐 App**：「复制歌单文本」/「导出 .txt」，每行「歌名 - 歌手」，在网易云 / QQ 音乐的导入歌单里粘贴（不碰任何非公开接口）
- **0308 自由情绪板**：一块大画布，立项时把素材摆成一版；穗图、穗卡、自由文字、四档灰阶色块随便拖；电脑滚轮缩放、拖空白处平移，手机单指拖、双指捏合；选中后可放大 / 缩小 / 拿掉 / 打开那一穗

导出
- **0339 Markdown 剪贴板**：「复制 Markdown」/「导出 .md」：草稿里的引用变成《标题》[n]，文末列溯源（类型 · 作者 · 年份 · 链接），分镜成表、歌单成列表、待办成勾选框，署名 Q1f730；不会把 uid 漏进去

**工程**
- Dexie version 11（新增 works 表，无数据迁移）；迁移回归套件加 v10 夹具（含穗束、反口味、私密穗、不要的理由），v1–v10 逐个升级到 v11 全过
- .glean 备份多一种行 `{"t":"work"}`：合并按 uid 取更新的、只补缺只加没有的、替换以备份为准；旧版读到这种行只是跳过
- 操作前快照带上作品，恢复时作品一起回去；v0.28 拍的旧快照（没有作品）恢复时不动作品表；自动备份的「库变没变」也看作品
- 作品页、情绪板、作品样式都懒加载，首屏 JS 只多 0.7KB（导航里多一项 + 新表定义）
- 新增单测 v029.test.ts（17 条，全量 403 条），e2e 新增 v029 组（手机：导航 / 立项 / 分镜与参考帧 / [[ 引用 / 预览 / 情绪板 / 导出 .md / 歌单 .txt / 影评检查 / 刷新后仍在 / 触达区 ≥44px；桌面：素材栏搜索加入并引用）

**没做 / 已知问题**
- 草稿编辑区里引用显示的是原始写法 `[[标题|uid]]`（26 位 uid 有点吵），「预览」里才是干净的穗；之后考虑换成带高亮的编辑器
- 歌单的「能量」是按文字里的词粗估的（没有音频分析），排序只是起点，请自己调
- 情绪板色块只给灰阶四档（照现有视觉），还不能从穗图里取色；画布没有撤销
- 这版不调用 AI：影评 / 短篇只给骨架和证据，不替你写正文（P1 里的 AI 扩写、开头十种等之后再做）
- 没在真机上验证：安卓上情绪板双指缩放的手感、底栏六项在 360 宽小屏上的观感
