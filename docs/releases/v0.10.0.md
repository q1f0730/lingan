## 拾穗 · Glean v0.10.0 — 改名，换一片麦田

*Glean what the day left behind.* 「灵感暗房」改名「拾穗 · Glean」，整体视觉从暗房红黑换成阿卡迪亚式的暖纸与麦田。

**下载**：安卓 `Glean_0.10.0_android.apk` · Windows `Glean_0.10.0_x64-setup.exe`（或 `.msi`）

**新功能**
- 改名拾穗：灵感库 → 穗仓，显影 → 嫁接，显影记录 → 新枝（现在是单独一页），口味画像 → 口味
- 背后是一整片活的 ASCII 麦田：远处麦浪随风滚过，地平线上一棵树；手指 / 鼠标划过会把麦子拨弯，快速一扫起一阵风，点空地飞起几粒种子，夜里有萤火
- 颜色随一天变化：清晨暖橙、白天麦金 + 叶绿、黄昏玫瑰、夜晚深色纸 + 萤火黄；设置 → 外观里可以固定某一段
- 内容浮在柔和的纸片上，标题用 Noto Serif SC Black，副标题是 Cormorant Garamond 斜体；字体全部自托管子集，不从网上拉
- 图片显影改成在纸上、用图片自己的颜色写成字符，再慢慢显成照片
- 热力图改成麦金深浅，默认滚到今天
- 新图标：一穗麦子
- 所有页面（穗仓、嫁接、新枝、口味、设置、速记、详情）都换成新风格，去掉了胶片编号、REC、曝光计时等装饰

**性能**
- 麦田用 canvas，只重画变化的格子；有动静时 24 帧，静下来 8 帧，25 秒没人碰降到 3 帧，切到后台完全停止
- 低端机自动用更粗的格子和更低帧率；系统开启「减少动态效果」或在设置里勾选「麦田静止」时只画一帧

**升级说明**
- 数据原样保留（数据库和应用标识没改）。安卓直接覆盖安装即可
- Windows 新版装在「Glean」下，旧的「灵感暗房 Lingan」可以在「设置 → 应用」里卸载；卸载时不要勾选「删除应用数据」

**修复**
- 速记和收集的按钮文字、提示统一成新用语
