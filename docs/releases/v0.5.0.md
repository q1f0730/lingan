## 灵感暗房 v0.5.0 — 「哇」第二弹：文字会解码，按钮有手感

**下载**：安卓 `Lingan_0.5.0_android.apk` · Windows `Lingan_0.5.0_x64-setup.exe`（或 `.msi`）

**新功能**
- 灵感库卡片入场错落浮现（前 12 张依次延迟，长列表不会等很久）
- 显影成果：标题从乱码一格格「解码」成真正的名字，正文逐字浮现（版面不会跳动）
- 按钮点击涟漪；电脑上鼠标靠近主按钮会被轻轻「吸」一下
- 动效三档自动适配：系统开了「减少动态效果」→ 全部关闭；低端机/省流量/核心少 → 精简版（更短、无磁吸）；其余完整版
- 全部零依赖，参考 reactbits.dev（MIT）的思路自己重写

**修复**
- 无
