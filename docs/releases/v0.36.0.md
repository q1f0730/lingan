## 拾穗 · Glean v0.36.0 — 系统能力接进来：截图、图中文字、浏览器扩展、说一句、通知

这一版把手机和电脑自带的能力接进拾穗，不往安装包和首屏里塞模型：Windows 上按 Ctrl+Shift+K 框一块屏幕，截完小窗带着图，补一句就存，图里的字由系统 OCR 认出来，秒搜搜得到；Chrome / Edge 装上拾穗扩展，右键就能拾「这一句」（以后点开直接滚回原句）、「这张图」，在 B 站 / YouTube 拾「当前时间点」连同那一帧；速记条多了一个「说」：安卓按住说话、松手成一穗，Windows 点一下唤出系统语音输入；嫁接时切走了，长好会发一条系统通知；安卓桌面多了 1×1 的「拾」小组件。

**下载**：安卓 `Glean_0.36.0_android.apk` · Windows `Glean_0.36.0_x64-setup.exe`（或 `.msi`）· 浏览器扩展 `glean-extension.zip`（新）· Agent 桥 / 命令行 `glean-mcp.mjs` · 校验 `SHA256SUMS.txt`

**升级**：Windows 装着 v0.25 – v0.35 的会自动收到（更新前先自动备份）；安卓 v0.26 起可以在 设置 → 更新 里直接「下载并安装」。数据库不变（仍是 Dexie v12），不用迁移；穗多了一个不加索引的 `ocr` 字段（图中文字），随备份和同步走。

**做了哪些（编号见 docs/ideas/ideas.csv）**

截图与图中文字
- **0005 框选截图热键**（Windows，默认 Ctrl+Shift+K，设置 → 极速采集 里可改 / 退格关掉）：调系统自带的框选截图，截完拾穗小窗弹出来、图已经放好，补一句回车就存成图片穗；取消截图什么都不发生。托盘菜单和设置里也有「框选截图拾」/「现在截一张」
- **0020 图中文字（Windows 系统 OCR）+ ROADMAP v0.30 截图里的字也能搜**：电脑上新收的图片穗（截图、粘贴、拖进来、发送到、扩展带来的）自动交给 Windows 自带的 OCR（离线、免模型、免 key、不发给任何人），认出的字存进穗里、进秒搜（结果标「图中文字」），详情里显示。手机上收的图同步到电脑后，在 设置 → 极速采集 →「识别旧图里的字」补认。电脑没装中文 OCR 语言包时提示一次去哪装，穗照样存

浏览器扩展（Chrome / Edge，新）
- **0008 拾这一句**：选中文字右键 → 存成摘抄，链接带 Text Fragment（`#:~:text=`），以后点开直接滚到原网页里的那一句（长句用「开头,结尾」）
- **0042 拾这张图**：图片上右键 → App 自己去下载原图（不受网页跨域限制），带页面标题和链接；还有「拾这个链接 / 这个页面」
- **0009 拾当前时间点**：B 站、YouTube 视频页右键（或点工具栏图标）→ 视频链接带上秒数（B 站 `?t=192`、YouTube `&t=192s`，去掉追踪参数），标题写「片名 · 3:12」；能截到当前帧时把那一帧放进剪贴板、桌面版一起收成图片穗，截不到只存时间码
- 所有内容都拼成 `glean://capture?…` 交给本机 App（新增 `img=` / `clip=1` 两个参数）；扩展不联网、不存东西。安装：解压 `glean-extension.zip`，在 `chrome://extensions` 打开开发者模式 →「加载已解压的扩展程序」

说一句就收（ROADMAP v0.26）
- 速记条（输入框空着时）多了一个「说」：**安卓**按住说话、松手成一穗（系统语音识别 SpeechRecognizer，第一次按时才请求麦克风权限；手机没有识别服务时退回系统语音输入框），收完照样可以补一句为什么；断网、没听清、没权限都会明说，不卡住。**Windows** 点一下 = 焦点放进速记框 + 唤出系统语音输入（Win+H），字直接打进框里，说完回车
- 只用系统能力，没有往安装包里放语音模型

入口与通知
- **0505 安卓 1×1 小组件「拾」**：放在主屏，点一下弹半屏速记卡（和磁贴同一个入口）
- **0509 系统入口先写收件队列**：安卓的半屏面板 / 磁贴 / 通知 / 小组件 v0.22 起就先写 `glean_inbox`；这一版桌面版也补上——冷启动带来的 glean:// 链接、「发送到」的文件路径先落盘（应用数据目录 `glean_inbox.json`），前端取走才删，拾穗在加载完之前被关掉 / 崩掉，下次启动还在
- **0519 统一系统通知**：手机和电脑都接 tauri-plugin-notification（前端直接调插件命令，不引 npm 包）；没权限就静默不发（安卓通知权限仍在第一次开常驻通知时说明再请求）
- **0527 嫁接在后台完成时发通知**：嫁接时切到别的窗口 / 锁屏，新枝长好发一条「新枝长出来了：A × B → 三根新枝的标题」

顺带
- 读剪贴板、重启安装更新改成直接调插件命令，剪贴板插件的 JS 包（连带一整个 Image 类）不再打进来，省下的地方装下了这一版的新功能，总资源没超预算（预算不放宽）

**剩余 P0 评估（大依赖类，都不进安装包首屏）**
- 0109 语义搜索 / 0106 母题聚类（要向量）：下一步走两条按需的路——已探测到的本机 LM Studio / Ollama 的向量接口，或设置里一键下载约 30MB 的小向量模型（独立分包 + 独立 IndexedDB，可删）；聚类在没有向量时用标签 + 为什么的 TF-IDF。可以做，不放弃
- 安卓图中文字：安卓没有系统级 OCR（ML Kit 要谷歌服务或往 APK 里塞约 10MB 模型），这版先在电脑上补认，不放弃

**性能**：同一 InstaBox 会话交替 9 轮冷启动（画完首帧）v0.35 190ms / 4× 降速 585ms，v0.36 194ms / 585ms，差异在噪声内（Mann-Whitney 不显著），持平；完整 e2e：冷启动 185ms（4× 518ms）、1000 穗搜索 ≤17.3ms、滚动 60fps 不掉帧、备份 97.5MB 640ms。新前端代码都懒加载（OCR 1.8KB 只在电脑上收图时加载、语音 1.7KB 只在按「说」时加载、通知 0.5KB）；首屏 JS 566.4KB（+1KB：速记条的「说」和收图后交给 OCR 的那一行），总资源 2226.0KB（预算 2226.6KB，没放宽）

**已知问题 / 没有真机验证**
- 没真机试过：Windows 上 `ms-screenclip:` 截图后剪贴板的时机（等最多 90 秒）、Windows OCR 中文识别质量（e2e 里 OCR 用模拟回应）、Win+H 在拾穗窗口里唤出的语音输入、tauri-plugin-notification 在 Windows / 安卓的样子、安卓 SpeechRecognizer 在 vivo（OriginOS）上有没有识别服务、1×1 小组件在各家桌面的大小
- 扩展：浏览器第一次会问「要打开拾穗吗」（勾「始终允许」）；B 站 / YouTube 的视频帧能不能截到取决于页面（跨域视频只存时间码）；视频帧经剪贴板带进来只在桌面版生效；扩展只做了 Chrome / Edge（Firefox 没做），也没上架商店（要加载已解压）
- 通知点开不一定直达结果（插件在 Windows 上不回传点击），打开拾穗后在嫁接页看
