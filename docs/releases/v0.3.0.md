## 灵感暗房 v0.3.0 — 零摩擦速记

**下载**：安卓 `Lingan_0.3.0_android.apk` · Windows `Lingan_0.3.0_x64-setup.exe`（或 `.msi`）

**新功能**
- 灵感库顶部常驻速记条：打一句话、贴一个链接，回车就存。`#标签` 直接写在句子里；链接会在后台自动识别成音乐 / 电影 / 图片 / 链接并补上标题和封面
- 存完不打断：下面冒出一行「为什么打动你？」，想补就补一句，不想补就忽略
- 剪贴板一键收：打开或切回 App 时，如果剪贴板里有新的文字或链接，会弹出「收进暗房？」，点一下就收；同一段内容只问一次，已收过的不再问
- 每张卡片都带记录时间（今天 22:18 / 昨天 / 10/19），详情里可以直接改时间
- 完整收集表单里「为什么」和「标签」默认收起，只在需要时展开

**修复**
- 收集表单字段过多导致的记录负担
