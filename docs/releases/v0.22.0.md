## 拾穗 · Glean v0.22.0 — 极速采集

这一版只做一件事：让「收」再快一步。在别的 App 里看到、听到、读到一句戳中你的东西，不用再把整个拾穗拉起来——半屏一弹，补一句为什么，存，1 秒回到原来的 App。

**下载**：安卓 `Glean_0.22.0_android.apk` · Windows `Glean_0.22.0_x64-setup.exe`（或 `.msi`）

**升级**：直接覆盖安装（安卓签名与 v0.20 / v0.21 相同的新密钥 + 轮换证明）。数据库不变（仍是 Dexie v8，没有新表、没有新索引；穗上多了一个可选字段 `source`「来自哪个 App」，旧数据不用迁移）。

**做了哪些（13 条，编号见 docs/ideas/ideas.csv）**
- **0001 分享进来改半屏「极速拾」**：安卓分享文字 / 链接 / 图片给「拾穗」时，不再拉起整个 App，而是一个透明主题的原生半屏面板（不启动 WebView）：类型 + 预览（图片缩略图 / 文字前几行）+ 一行「为什么」+ 存。存完自动回到原来的 App；点空白处或返回 = 取消。链接的标题封面等你下次打开拾穗时自动补上
- **0002 长按选字菜单「拾穗」（PROCESS_TEXT）**：在微信读书、浏览器、知乎里选中一句话，浮动菜单里点「拾穗」，同一个半屏面板，只读不回写原文
- **0057 选字收成摘抄 + 带来源**：选字收进来的一律是「文案」类型 + `摘抄` 标签，自动记下来自哪个 App（如「微信读书」），作者留空；详情页显示「来自 微信读书」和醒目的「作者 · 待补」，点一下直接进编辑
- **0028 记住分享来源 App**：分享 / 选字 / 正在播放都会记来源（选字菜单用 callingPackage，分享用 referrer，再用系统应用名翻成中文；认不出就留空，不猜）。Obsidian 导出多一个 `拾自` 字段
- **0056 面板里 3 个最近用过的标签**：最近 20 穗里最常用的 3 个（「分享」「摘抄」这类自动标签不算），点一下打上，再点取消
- **0010 安卓「正在播放一键拾」**：读系统媒体会话（网易云 / QQ 音乐 / 汽水 / Spotify…）的歌名、歌手、专辑和封面，存成音乐穗（`正在听` 标签 + 来源 App）。入口：磁贴「拾这首歌」、常驻通知按钮、小部件、长按图标、App 内速记表单的「♪ 当前歌曲」
- **0556 权限第一次用时才说明并请求**：读正在播放需要「通知使用权」，常驻通知在安卓 13+ 需要通知权限——都是在你第一次点到相关功能时，先用一句话说明为什么、只读什么，你点「去打开 / 继续」才跳系统设置或弹系统权限框；被拒或选了「不再询问」时给「去系统设置」。首次启动不弹任何权限
- **0011 Windows「正在播放一键拾」**：经系统媒体传输控件（SMTC）读当前播放的歌（Rust `windows` crate，无需任何权限）。入口：托盘菜单「拾正在播放的歌」（一键存）和 Ctrl+Shift+L 速记小窗里的「♪ 当前歌曲」
- **0007 快捷设置磁贴**：「拾一穗」（下拉一点就弹半屏速记）和「拾这首歌」（有通知使用权时一点就收，不弹任何界面）
- **0041 常驻通知「随手拾一穗」**：设置 → 极速采集里打开。通知栏里直接打字回车就存（RemoteInput），旁边一个「♪ 拾这首歌」按钮；存完通知里显示「已拾：…」。不用前台服务；开机 / 升级后自动补回
- **0006 桌面 4×1 小部件**：拾一穗 / 粘贴 / ♪ 这首歌 / 穗仓 四个纯文字按钮，跟随系统深浅色
- **0022 长按图标快捷方式**：拾一穗 / 粘贴拾 / 拾这首歌 / 今日一穗
- **0025 采集草稿永不丢**：速记栏、速记小窗、速记表单里打的字 500ms 防抖存本地；App 被杀或崩溃后下次打开自动「接着写」（可一键清掉）；存进穗仓后草稿删除，7 天前的旧草稿不再恢复

**怎么接进穗仓（技术说明）**：半屏面板 / 磁贴 / 通知 / 小部件都只往 App 私有目录的收件箱写一条 JSON（图片另存一个文件，先写临时文件再改名），uid 在原生端按 v0.21 同一种 ULID 生成。主界面每次回到前台时逐条收进 IndexedDB：保留你按「存」那一刻的时间和这个 uid，照常盖 v0.21 的 updatedAt / deviceId，成功后才删除收件箱里那一条；同一个 uid 已在库里就只删不重复收。所以「存」在面板里是即时的，穗出现在穗仓里要等你下次打开拾穗。

**设置 → 极速采集**：列出这台设备上可用的入口；安卓上有「常驻通知」和「通知使用权」两个开关（状态跟着系统设置实时变）。

**⚠️ 没有真机验证的部分**（CI 只证明能编译、能打包、签名正确；下面这些需要在 vivo / Windows 上实际点一遍）
- 半屏面板的实际弹出速度（目标 < 400ms）、在各家系统上的透明 / 圆角 / 输入法顶起效果，存完是否都能回到原 App（个别 App 用自己的分享面板时可能回到桌面）
- 选字菜单里「拾穗」是否出现：部分 App（如微信聊天、某些自绘文字的阅读器）不提供系统选字菜单；vivo OriginOS 可能把它收在「更多」里
- 来源 App 识别：部分 App 分享时不带 referrer，会显示为空
- 正在播放：各音乐 App 的媒体会话是否都带封面 / 专辑；vivo 的「通知使用权」设置页路径可能与原生安卓不同
- 磁贴需要自己在快捷设置编辑里拖出来；小部件在 OriginOS 桌面的尺寸和深色模式
- 常驻通知的回复框在锁屏上的行为；国产系统可能在「省电」时清掉常驻通知（开机后会补回）
- Windows SMTC：只有把播放状态报告给系统的播放器才读得到（网易云 / QQ 音乐 / Spotify / 浏览器网页播放一般可以；部分老版本客户端不行）

**没做 / 推迟**
- 0006 小部件原文是「文字 / 拍照 / 语音 / 剪贴板」：拍照和语音需要原生相机 / 录音流程，换成了「♪ 这首歌」和「穗仓」；语音放到「说一句就收」那一版
- 0556 原文针对「嫁接完成提醒」，那个功能还没有；本版把同一原则用在常驻通知和通知使用权上
- 同组 P0 里 0003（剪贴板图片）、0004（快捷键自动带选中文字）、0005（截图成穗）、0012（短链展开）、0021（开机自启预热）等这版没做，留给下一轮采集包

**已知问题**
- 极速拾存下的穗要等下次打开拾穗才出现在穗仓、才做链接解析和 AI 整理（面板不启动 WebView，换来的是速度）
- 卸载重装会清掉还没收进穗仓的收件箱条目（它们在 App 私有目录里）
