## 拾穗 · Glean v0.28.0 — 拾穗动线

这一版把「看 → 攒 → 成束 → 嫁接」这条路接顺：浏览时长按 / 右键把穗丢进待嫁接篮，满 3 穗一键嫁接；一组穗可以存成穗束（如「毕业设计参考」「想写的歌」），嫁接时可以只在某个束里抽；大屏电脑上穗仓变三栏，单击右边就预览；搜索认拼音和首字母（wjw → 王家卫）；速记条认行内语法（《重庆森林》 @王家卫 > 雨夜里的霓虹），分享过来的抖音 / 小红书 / 淘宝口令会抽出真实链接、链接里的追踪参数自动剥掉；第一次打开时，第一屏就能真的拾下第一穗。

**下载**：安卓 `Glean_0.28.0_android.apk` · Windows `Glean_0.28.0_x64-setup.exe`（或 `.msi`）· Agent 桥 / 命令行 `glean-mcp.mjs` · 校验 `SHA256SUMS.txt`

**升级**：Windows 装着 v0.25 – v0.27 的会自动收到（更新前先自动备份）；安卓 v0.26 起可以在 设置 → 更新 里直接「下载并安装」。数据库**不变（仍是 Dexie v10）**，没有迁移：穗束存在每一穗自己的 `bundles` 字段里（没加索引），备份 / 导入原样带着。

**做了哪些（9 条，编号见 docs/ideas/ideas.csv）**

嫁接动线
- **0408 常驻待嫁接篮**：长按卡片（电脑右键）或详情里点「放进嫁接篮」，随手攒。篮子手机在底栏速记条上面、电脑在侧栏底部，空着不出现；圆点显示还差几穗，满 3 穗「嫁接这 N 穗」一键带进嫁接页（最多 5 穗，满了挤掉最早那穗），嫁接后篮子清空。展开能看篮里有谁、单个拿出、存成穗束、清空。多个窗口共用一个篮子
- **0107 穗束（合集）**：一穗可以属于好几个束。详情多一行「穗束」：点「＋束」加（逗号分隔一次加几个），点「束 · X」回穗仓看这一束，✕ 拿出来；篮子里的一把可以一次存成束。穗仓筛选栏多出「束 · X (n)」，搜索语法加 `束:毕业设计`（`束:空` = 不在任何束里）
- **0108 穗束当嫁接池**：嫁接页顶上「从哪抽：整个穗仓 / 束 · X」，选了束就只在这个束里抽（接法、换一穗都只在束里）；穗仓里筛到某个束（≥3 穗）时有「从这一束里嫁接」

浏览与搜索
- **0402 桌面三栏**：窗口宽 ≥1500px 时，穗仓变成 导航 / 列表 / 右侧预览：单击卡片在右栏看详情（当前那张描边），← / → 翻、Esc 关，双击或点「整页」才开整页详情；右栏开着时「今天」栏先收起，给列表让位。1024–1499px 保持原来的整页详情
- **0112 拼音与首字母搜索**：搜索框里打纯字母时，标题 / 作者 / 标签的拼音对得上的也列出来（排在原文命中后面）：`wjw`、`wangjiawei`、`jiawei` 都能找到王家卫；多音字认常用的几个读音（`chongqing` 找得到重庆森林），最后一个音节可以只打一半。字表（GB2312 6763 字）只在第一次打字母时加载，不进首屏

速记
- **0024 速记行内语法**：`> 为什么`（> 后面到结尾都算为什么）、`@作者`、整句是 `《片名》`（可带年份）就存成电影、`/歌 /影 /文 /链接 /想` 强制类型；和 `#标签` 可以一起写。邮箱、链接里的 @ 不算
- **0019 平台口令**：抖音「复制打开抖音，看看【…的作品】…」、小红书「复制本条信息，打开【小红书】App…」、淘宝口令等分享文案，自动抽出真实链接、去掉套话和口令码当标题，并记下来自哪个 App
- **0023 链接剥追踪参数**：utm_*、spm_id_from、vd_source、share_source、xsec_token、si、fbclid 等统一去掉；from / key / lang 这类有歧义的只在对应的站（B 站、微信文章、淘宝、网易云…）上删，内容参数（id、t、p…）不碰

首次打开
- **0404 首启真的拾第一穗**：引导第一屏有一条速记条，打一句（或点一个示例：`《重庆森林》 @王家卫 > 雨夜里的霓虹`）回车就真的存进穗仓，马上给你看存成了什么类型、作者、为什么；不想拾也可以直接「开始」或「跳过」。引导页本身改成懒加载，老用户冷启动不再下载它
