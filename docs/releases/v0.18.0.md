## 拾穗 · Glean v0.18.0 — 五种嫁接

嫁接页可以选「接法」了：相近、远距、被冷落、跨媒介、反氛围。每种接法有自己的抽穗规则，规则会写进给模型的提示词，没配 AI 的离线嫁接也支持这五种。从这一版起，App 会记录每件穗被嫁接了几次、最后一次是什么时候，所以「被冷落」能准确抽到最少被用过的那几穗。

**下载**：安卓 `Glean_0.18.0_android.apk` · Windows `Glean_0.18.0_x64-setup.exe`（或 `.msi`）

**新功能**
- 嫁接页新增「接法」，五个选项都是纯文字，点一下就按这种接法重新抽一组穗（几穗沿用当前设置）。选中的接法加粗、加下划线，下面一行「怎么抽」写着它的抽样规则。上次用的接法会记住，默认是远距
  - **相近**（挑气质接近的）：先随机抽一穗做起点，之后每次从与已选几穗平均最相像的前三穗里抽一穗
  - **远距**（故意挑最不搭的）：先随机抽一穗做起点，之后每次从与已选几穗平均最不相像的前三穗里抽一穗，类型尽量不重复
  - **被冷落**（优先从没接过的）：按被嫁接次数从少到多排，只从全库最低的一档里抽。同一档里先抽从没接过的，再抽最久没接的。已选的穗旁边会标「接过 n 次」或「没接过」
  - **跨媒介**（照片接歌，摘抄接电影）：每组至少 3 种类型。先每种类型抽一穗（类型之间尽量远），再按最不相像补满。穗仓里类型不够 3 种时会提示「穗仓里只有 n 种类型，跨媒介至少要 3 种」
  - **反氛围**（把一穗的反面接上去）：第一穗做锚，其余几穗优先挑和锚的氛围相反的（静↔闹、明↔暗、暖↔冷、轻↔重、旧↔新、自然↔人造），氛围一样相反时再挑和已选最不相像的
- 「换一穗」也遵守当前接法：被冷落只从剩下的最低档里补，跨媒介优先补一种还没有的类型
- 接法会写进模型的提示词，两次调用都带：接法名、抽样规则、对新枝的要求，以及这一组的具体情况。被冷落会写每穗被接过几次，跨媒介会写这组有哪几种媒介，反氛围会写锚的氛围和它的反面
- 离线嫁接同样分五种。第一根新枝固定用这种接法最合适的变形法：相近 → 拿掉最显眼的，远距 → 撞年代，被冷落 → 保留瑕疵，跨媒介 → 换媒介，反氛围 → 反转。第一条张力会说明这组为什么这么抽（例如「《凌晨的雾》是「安静」的，把它的反面「热闹」接上去」），每根新枝的正文里也有一句接法说明
- 结果标题会写出用的接法，例如「一次三枝 · 跨媒介 · 离线嫁接」。按钮写成「按「被冷落」嫁接这 3 穗」
- 从每日一穗或穗详情带进嫁接页的穗，保持原来那组，不套用接法，页面上会说明。这时点任一接法，就按那种接法重新抽

**嫁接次数**
- 每件穗新增「被嫁接次数」和「最后一次嫁接时间」。一次嫁接（同一批三根新枝）算 1 次
- 数据库升到 Dexie version 6。升级时按已有新枝回填：同一批三根算一次，v0.11 以前的单根新枝每根算一次。从没被接过的穗补 0。穗和新枝的内容都不改动
- 导入旧备份（里面没有次数）时，按一起导入的新枝回填；新版本导出的备份会带上次数，导入时原样保留
- 穗详情多一行「嫁接：n 次 · 最后 10/22」，没被接过的显示「还没接过」

**没变的**
- 每日一穗、今日三穗、新枝溯源（每根新枝都能点回 ≥3 穗）、证据不足标记、四步嫁接与重试退避，都和以前一样
- 视觉照旧是 v0.16 的 Studio，对照 m23（手机选穗与接法）和 d4（电脑嫁接结果）设计稿：黑白灰，无图标、无圆角、无阴影；电脑上五种接法横排
- 原来的「跳跃度」滑块去掉了，由「相近 / 远距」两种接法代替

**测试**
- 单测 171 条（新增 25 条，在 src/__tests__/modes.test.ts），覆盖：
  - 相近只在同一簇里抽，远距每一穗都来自离起点最远的前三，并且两簇都会被抽到
  - 被冷落抽到的穗次数都在全库最低档：次数比门槛少的全部被抽到，其余不超过门槛；同一档里先抽没接过的，再抽最久没接的；换一穗时同样遵守
  - 跨媒介在库里类型够时，每组至少 3 种类型（3 / 4 / 5 穗各测 25 次）；类型不够时给出提示
  - 反氛围：第二穗和锚的氛围相反程度是全库最高的
  - 五种接法的规则和要求都写进了两次调用的提示词
  - 离线五种接法都是三根新枝，变形法两两不同，每根都能点回 ≥3 穗
  - Dexie v5 → v6 迁移、markGrafted 次数 +1、导入旧备份时回填
- e2e：
  - 新增 modes()：断网、不配 key，五种接法各跑一次离线嫁接，「被冷落」跑两次。每次都核对：抽样规则、新枝带上了接法、只有被选中的穗次数 +1、「被冷落」抽到的都是全库最低档、「跨媒介」至少 3 种类型、穗详情显示次数；穗仓只有一种类型时选跨媒介会出提示；电脑版横排截图
  - AI（模拟模型）嫁接时，核对两次调用的提示词都带上了当前接法
  - 旧库（v1 结构）升级后，嫁接次数按旧新枝回填为 [2, 2, 1]

**已知限制**
- 氛围是按一份固定词表从穗的文字里读出来的（六组相反的词）。读不出氛围的穗只按「最不相像」来挑
- 相近 / 远距的相似度：有向量时用向量，没有时用字面相似
