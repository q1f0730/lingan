## 拾穗 · Glean v0.42.0 — 嫁接成绩 · 配方

这一版让嫁接「有成绩、能复用」：每根新枝可以轻轻评一下「有多意外」，复制、分享、留下、推进、追问都会被当成「用上了」；口味页多了一块「嫁接成绩」——证据覆盖、三枝差异、平均意外、采用率，还有最常被用上的「高产穗」和每种变形法的 用上 / 长出。一次满意的嫁接可以「存成配方」，下次一点就照样来；嫁接页多了两种特别抽法：「时间差」（一穗一年以前的 + 一穗这周的）和「标签对撞」（两个从没同时出现过的标签各出一穗）。从新枝点进某一穗，详情顶上会有「← 回到新枝 01」。

**下载**：安卓 `Glean_0.42.0_android.apk` · Windows `Glean_0.42.0_x64-setup.exe`（或 `.msi`）· 浏览器扩展 `glean-extension.zip` · Agent 桥 / 命令行 `glean-mcp.mjs` · 校验 `SHA256SUMS.txt`

**升级**：Windows 装着 v0.25 – v0.41 的会自动收到（更新前先自动备份）；安卓 v0.26 起可以在 设置 → 更新 里直接「下载并安装」。数据库不变（仍是 Dexie v12），不用迁移；新枝多了几个不加索引的字段（意外程度、最后一次复制 / 分享、模型 / 提示词版本），随同步走；配方只存在这台设备上。

**做了哪些（编号见 docs/ideas/ideas.csv）**

这根新枝怎么样
- **ROADMAP v0.32 意外程度 + 嫁接成绩**：新枝卡「有多意外」1–5（1 早想到了，5 完全没想到；再点一次取消）。口味页「嫁接成绩」：证据覆盖（说得出从哪 ≥3 穗长出来的占比）、三枝差异（每次三根里最像的那一对，1 − 相似度再平均）、平均意外（评了几根）、采用率
- **ROADMAP v0.32 可复现**：每根新枝都记下用的模型、提示词版本（p42）和温度，卡片底下一行「模型 glm-4.7-flash · 提示词 p42」；离线的写「离线嫁接」，以前长的写「早先的」
- **0238 采用信号**：留下、推进到「试过 / 做成」、附了结果图、复制或分享过、追问过、再嫁接过，都算这根被用上了；标成「放弃」的不算
- **0239 高产穗**：被用上的新枝引用最多的 5 穗，点一下打开
- **0240 变形法胜率**：八种变形法各自 用上 / 长出；攒够 12 根后，用上得明显多的（最多 2 种）会写进 AI 收拢那一步「同等条件下优先」——撒种子那一步仍是八种各一粒，三根仍然变形法两两不同
- **0221 停在这一档几天了**：「做了吗」旁边显示「「种子」第 3 天」，从上次推进那天算
- **0243 借了这一穗的哪句话**：「因为这几穗」每张小卡下面标出新枝借用的那一段（新枝正文和这穗的为什么 / 内容 / 描述 / 标签里最长的共同片段，汉字至少 3 个；标题和作者不算，上锁的穗不算），全离线

嫁接配方与特别抽法
- **0213 嫁接配方**：长完三根后「存成配方」，把接法（或特别抽法）、几穗、方向、野一点、先挑张力、从哪个穗束抽一起记下，自动起名（「标签对撞 · 3 穗 · 一首歌的 MV · 野」）；嫁接页「配方」一点就照它抽一组，× 删掉；最多 8 个，只存在这台设备
- **0214 时间差嫁接**：「特别抽法 · 时间差」：一穗满一年的 + 一穗最近 7 天的，其余按远距补满，说明里写「「旧片一」是 1 年前拾的，「这周的窗」是这周拾的」；没有满一年的穗或这周没拾过会直接说缺什么
- **0217 标签对撞**：「特别抽法 · 标签对撞」：从最常用的标签里找两个从没同时出现在一穗上的（优先两边都有 ≥2 穗的），各抽一穗，其余按远距补；说明写「#城市 × #海」

导航
- **0421 回到新枝**：从新枝卡的「因为这几穗」点进某一穗，详情顶上一条「← 回到新枝 01《倒过来的旧歌二》」，点了关掉详情、滚回那根新枝；从穗仓打开同一穗不会出现

瘦身（预算不放宽）
- 示例池（空穗仓时「放几条示例」）改成压缩包、只在点的时候才下载解开，首屏 JS 少了约 12KB；拼音字表、繁简字表也压缩进包，用浏览器自带的 DecompressionStream 解开。省下的地方给了这一版的新功能

**性能**：（1000 穗，同一台测试机同一会话交替 9 轮 ×2，首帧画完的中位数）冷启动 v0.41 182 → v0.42 190ms、换先后顺序再测 197 → 203ms；4 倍降速 550 → 570ms、605 → 610ms，两轮都在误差内（性能回归门 OK）；秒搜 ≤20.6ms，滚动 60fps，备份 1000 穗 / 300 图 658ms。首屏 JS 539.0 → 526.9KB、首屏 CSS 118.5KB、首片字体 286.0KB 不变，总资源 2223.3KB（预算 2226.6KB 不放宽）。详见 docs/perf/v0.42.0.json。

**没做 / 留到之后**
- 0222 口味来源链、0219 新枝拆成三步、0220 新枝缺一穗（要调模型，下一包 AI 类一起做）
- ROADMAP v0.29 后台队列、v0.33 到点递一穗、v0.36 色谱，0924 封存到某天

**已知问题 / 没有真机验证**
- 「借了哪句话」是按字面找最长共同片段，模型换了说法就找不到；只是提示，不是证据判定
- 变形法偏向要攒够 12 根带变形法的新枝才开始，且只影响 AI 嫁接（离线嫁接照旧）
- 配方不进备份 / 同步（本机设置）；换设备要重新存
