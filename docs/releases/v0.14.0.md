## 拾穗 · Glean v0.14.0 — 每日一穗

*One ear a day.* 每天第一次打开，穗仓顶部递给你一张「今日」卡：三件很久没碰的旧穗，加一组从没一起嫁接过的远组合，点一下就带进嫁接。示例也从固定的 10 条换成了约 80 条的池子。

**下载**：安卓 `Glean_0.14.0_android.apk` · Windows `Glean_0.14.0_x64-setup.exe`（或 `.msi`）

**新功能：每日一穗**
- 穗仓顶部的「今日一穗」卡：
  - **很久没碰的三穗**：从最久没打开、没编辑、没拿去嫁接的那一截里挑（最近 3 天碰过的不算），每件标着「N 天没碰」，点开直达详情
  - **没试过的远组合**：以其中一件旧穗为锚，再挑三件离它最远、类型尽量不同的穗；已经一起嫁接过的组合会被让开
  - **一键去嫁接这 4 穗**：直接跳到嫁接页，4 件素材已经选好（几穗 = 4），有没有 AI key 都能长出三根新枝
- 同一天内容不变：按日期定下来并存在本机，反复打开、打开看了其中一穗、刷新都一样；第二天换一批，并避开昨天那三件旧穗
- 完全离线：只用本机数据，断网、没填 API key 也照样出现
- 「收起」只管当天，第二天重新展开
- 穗不到 4 件时不出卡；自己的穗够 4 件后，第二天起只从自己的穗里挑，不再用示例

**新功能：示例池**
- 示例从写死的 10 条扩成约 90 条：电影（七武士、疯狂的麦克斯、千与千寻、闪灵、上帝之城、三傻大闹宝莱坞、地球脉动…）、音乐（Billie Jean、Juicy、Fela Kuti、Metallica、BTS、竹内玛莉亚、崔健、Despacito…）、图片（神奈川冲浪里、地出、夜游者…，示例不带图，用文字描述）、摘抄、想法、链接，横跨十几个国家、从 14 世纪到 2020 年
- 空穗仓点「先放点示例」时随机抽 10 条，六种类型各至少一条，每次都不一样
- 示例卡片和详情都标着「示例」；穗仓顶部有「清掉示例」（只删示例，你自己的穗和新枝一条不动）和「换一批」
- 示例的「拾于」时间铺在过去 3–90 天里，好让时间线和每日一穗一上来就有东西；但示例不会出现在「一周前的你 / 那年今天」回顾里
- 示例池约 90 条里的字大多走按需加载的字体分片，常驻首片反而比上一版小一点

**升级说明**
- 数据库升级到第 4 版，自动迁移：给每件穗补上「最后一次被拿去嫁接」的时间（用来判断很久没碰），新增每日一穗记录表；穗、图片、新枝一条不动
- 备份格式不变，旧备份照常能导入

**测试**
- 单测 132 条（新增每日一穗确定性 / 第二天变化 / 避开刚碰过的 / 组合没试过、v3→v4 迁移、示例池覆盖与清除）
- e2e 新增「每日一穗」整段：掐掉所有外部请求、没有 key；同一天刷新两次一致、第二天变化、回到当天仍是原样；浏览器离线后一键带进嫁接，4 穗已选好并离线长出三根；换一批 / 清掉示例只留自己的穗
- 测试和 e2e 不再写死那几条示例，改为按种子 / 按实际抽到的示例断言
