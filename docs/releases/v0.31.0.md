## 拾穗 · Glean v0.31.0 — 同步 · 一：经你自己的网盘，端到端加密

这一版手机和电脑终于能用同一片穗仓了：在设置 → 同步里填上坚果云（或任何 WebDAV 网盘）的账号和应用密码，设一个同步口令，另一台设备用口令或恢复码加入，穗、新枝、作品、套路墙、不要的理由和原图就会两边合并。上传前全部在本机加密，网盘里只有密文；两台设备改了同一穗的不同地方，两处修改都会留下。每次拉到东西之前先拍一张快照，不满意可以一键回到同步前。口味原子、自己写的斜策略卡和出站记录也进了 .glean 备份和操作快照。

**下载**：安卓 `Glean_0.31.0_android.apk` · Windows `Glean_0.31.0_x64-setup.exe`（或 `.msi`）· Agent 桥 / 命令行 `glean-mcp.mjs` · 校验 `SHA256SUMS.txt`

**升级**：Windows 装着 v0.25 – v0.30 的会自动收到（更新前先自动备份）；安卓 v0.26 起可以在 设置 → 更新 里直接「下载并安装」。数据库升到 **Dexie v12**：五张会同步的表每行加 `hlc` / `hc` / `fh`（混合逻辑时钟），迁移只按每行自己的修改时间和设备补字段，不动任何内容；升级前照旧自动存一份原始库副本。

**做了哪些（10 条编号 + v0.30 遗留一项，编号见 docs/ideas/ideas.csv）**

同步地基
- **0602 每行 HLC + deviceId + modifiedAt**：混合逻辑时钟（毫秒 + 计数 + 设备 id，字符串比较就是先后；本机时钟回拨不倒退，收到别的设备更新的时间会追上）。新建、改动自动盖章，并按字段记下「这个字段是哪一刻改的」
- **0619 字段级 LWW 合并**：每个字段各取最新的一边：手机改了标题、电脑同时改了「为什么」，两处都留；进回收站也是一个字段，照样按先后合并
- **0620 合并引擎属性测试**：300 组随机编辑史验证交换 / 结合 / 幂等；3 台设备随机增、改、删、彻底删、随机顺序同步 60 步，最后三边完全一致（3 个种子）
- **0628 派生数据不进同步**：缩略图、向量、重复钥匙、标签建议、嫁接次数、套路墙计数都不传，对端自己重建
- **0612 同步层接口 SyncTransport**：列目录 / 取 / 放（只追加，不覆盖）/ 删，换后端不动同步逻辑；这一版实现了 WebDAV 和内存（测试），下一版的局域网直连也只是再实现一次
- **0613 文件型同步协议**：每台设备只追加自己的改动包 `ops/<设备>/<序号>.op`（只推 HLC 比上次推过的新的行，大的分包），隔一段写一份全库快照 `snap/<设备>.snap`，新设备先从最全的快照起步再补后面的包；本机状态丢了也接着云上的序号往后写，绝不覆盖旧包；彻底删除记墓碑推给别的设备
- **0614 WebDAV 同步，预设坚果云**：选「坚果云」只填登录邮箱和应用密码（坚果云网页 → 账户信息 → 安全选项 → 第三方应用管理 → 添加应用）；「自定义 WebDAV」可填 Nextcloud / 群晖 / Alist 等。应用密码存进系统钥匙串，不进设置、备份和诊断。打开时、回到前台时、开着的时候每 10 分钟自动同步（可关），也可以手动「立即同步」
- **0616 端到端加密**：随机 256 位数据钥，云上每个文件都是 AES-256-GCM 密文（绑定文件路径，挪动 / 改字节都解不开）；同步口令经 Argon2id（19 MiB、2 轮）派生包裹钥包住数据钥，网盘服务商和拿到网盘的人都看不到内容；原图按内容寻址加密上传，同一张只传一次。换同步口令只重新包一下数据钥，云上数据不用重传
- **0618 恢复码**：新建同步时生成一张恢复码（8 组 4 位 Crockford Base32，可复制 / 打印成卡片），只显示一次，必须输入最后一组确认抄好了才开始同步；忘了口令时在新设备上用它加入（大小写、空格、I/L/O 都宽容）
- **0615 同步前自动快照，一键回到同步前**：每次拉到别的设备的修改、写本机库之前先拍一张操作快照；「回到同步前」让本机回到那一刻，并把这次「回去」作为最新的修改推出去——别的设备下次同步也跟着回去，那次新来的穗进回收站（30 天内能找回），不会被下次同步又拉回来

v0.30 遗留
- **口味原子、自写斜策略卡、出站记录进备份**：.glean 多一行 `{"t":"local"}`，导入时按「合并 / 只补缺 / 替换」处理（原子按文字去重、自己改过的排前；卡取并集；出站记录按时间去重，上限照旧）；操作快照也带上，恢复快照时一起回去。旧版读到这一行会计入「1 行读不出，已跳过」，不影响导入

**留到下一版（v0.32 同步 · 二）**：ROADMAP「手机电脑同一片麦田」的局域网直连（电脑显示二维码、手机扫码、同一 Wi-Fi 下不经服务器）——要在桌面端起一个局域网服务，复用这一版的 SyncTransport 与合并引擎；云上旧包的清理（现在只追加不删）。

**已知问题 / 没有真机验证**
- 没有在真的坚果云账号上跑过（e2e 用的是按 WebDAV 协议回应的内存服务）；坚果云对 `If-None-Match` 的支持没核实，不支持时仍靠「先列目录、序号接着往后」防覆盖
- 网页版（浏览器里打开）连坚果云会被跨域拦下，同步请用安卓 / Windows App（App 里走原生网络，不受跨域限制）
- 「清空」只清本机：开着同步时清空后，下次同步会从云端把全部拉回来；要彻底停用先「断开」
- Windows 钥匙串 / 安卓 Keystore 存应用密码与数据钥没在真机上验证
