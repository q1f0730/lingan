## 拾穗 · Glean v0.27.0 — 顺手

这一版专门磨手感：手机上长按卡片有菜单、速记条贴着键盘、全面屏不再被状态栏和手势条压住、所有按钮都好按；电脑上 Ctrl+V 或把图片 / 链接 / 文件拖进窗口就成穗，右键卡片有菜单；详情里的标题、为什么、标签点一下直接改；打 # 就有标签候选；切页回来还在刚才那张卡。顺带修了手机上快照 / 备份列表的长文字被截成「…」。

**下载**：安卓 `Glean_0.27.0_android.apk` · Windows `Glean_0.27.0_x64-setup.exe`（或 `.msi`）· Agent 桥 / 命令行 `glean-mcp.mjs` · 校验 `SHA256SUMS.txt`

**升级**：Windows 装着 v0.25 / v0.26 的会自动收到（v0.26 起更新前会先自动备份）；安卓 v0.26 可以在 设置 → 更新 里直接「下载并安装」。数据库**不变（仍是 Dexie v10）**，没有迁移。

**做了哪些（13 条，编号见 docs/ideas/ideas.csv）**

手机
- **0401 速记条贴住软键盘**：在速记条里打字时，底部导航收起，只留速记条贴在键盘上沿，不被盖住、不跳。安卓由原生把键盘高度交给页面；网页版用 visualViewport 算键盘高度
- **0410 全面屏安全区**：安卓 11+ 改成边到边显示，状态栏、刘海、手势条的实际尺寸由原生写给页面，顶栏、详情页、底栏各自让开，内容不再压在状态栏下或被手势条挡住；安卓 9–10 保持原来的布局
- **0416 状态栏 / 标题栏跟主题**：切到黑主题，安卓状态栏和导航栏图标变浅色、白主题变深色；Windows 窗口标题栏跟着变黑 / 白；网页的 theme-color 同步
- **0411 长按卡片出菜单（电脑右键同款）**：打开 / 编辑 / 拿去嫁接 / 复制文字 / 复制链接 / 删掉。手机从底部升起，电脑贴着鼠标、不出屏幕，↑↓ 和 Esc 可用；长按松手不会再顺手打开详情
- **0414 触达区 ≥ 44×44**：手机上所有按钮、标签、开关的可点范围至少 44×44（透明扩大点击区，外观不变）。e2e 逐个量穗仓、设置、详情三页的可点元素，现在 0 个不达标

速记
- **0412 速记时显示识别出的类型**：速记条里一打字，右边出一个小标「音乐 / 电影 / 链接…」，点一下换下一种，存的就是换过的类型
- **0413 #标签自动补全**：在速记条、「补一句」、速记小窗、详情加标签、编辑表单的标签栏里，打 # 或标签的头几个字就出候选（按你用过的次数排，已填的不再出），Tab 填第一个、↑↓ 挑、点一下也行；回车照常存，不会把「#雨」偷换成「#雨夜」
- **0405 速记小窗粘贴图片、拖入文件**：Ctrl+Shift+L 唤出的小窗里直接 Ctrl+V 截图，先出缩略图，回车连同那句话存成图片穗；拖一张图进来同样；拖多个文件进来直接各成一穗
- **0406 任意处 Ctrl+V 成穗，Ctrl+N 打开完整表单**：不在输入框里时，穗仓任意位置 Ctrl+V：文字 / 链接走速记同一套识别，截图成图片穗（剪贴板截图叫「粘贴的图片」）；输入框里粘贴照旧。Ctrl+N 打开完整速记表单（网页版里可能被浏览器自己抢走，桌面版一定好用）
- **0407 拖进窗口任意处成穗**：把图片、网页链接、一段文字、.txt / .md 拖进窗口，整窗出现「松手就拾进穗仓」，松手即收（一次最多 20 个）；PDF 等其它文件跳过并告诉你跳过了几个。桌面版为此改用网页拖放（tauri.conf.json dragDropEnabled=false）

浏览与编辑
- **0403 回到原来的位置和那张卡**：切到别的页再回穗仓，回到刚才看的那张卡附近（按锚点卡追位置，上方模块晚到、瀑布流重排也不跑偏），不再一律回顶；关掉详情（翻过上一穗 / 下一穗就是最后看的那张）后那张卡轻轻描一圈、拿到焦点
- **0409 详情字段点一下直接改**：标题（摘抄改原文）、作者 / 歌手 / 导演、年份、内容、为什么收都能点一下变输入框，回车（多行 Ctrl+回车）或点别处保存，Esc 放弃且不关详情；「为什么收」空着时直接显示「点这里补一句」，写进去的 #标签自动进标签；标签后面多一个「＋标签」。改过的内容会重算向量
- **0417 多窗口实时同步**：开两个窗口 / 标签页，一个里收的穗另一个立刻出现（Dexie 跨窗口通知），一个里改了主题等设置另一个跟着变

**修复**
- 手机上「操作前快照」「自动备份」列表的说明、时间、条数被截成「…」：改成折行显示，操作按钮挪到下一行，文字占满整行；设置里各行的说明（如「可以选坚果云 / OneDrive 的同步文件夹…」）窄屏也折行。e2e 在手机宽度逐格核对没有省略号

**性能**（数字见 docs/perf/v0.27.0.json）
- 同一 InstaBox 会话交替测 7 轮（1000 穗 / 300 图）：v0.26 冷启动 188ms、4× 降速 562ms；v0.27 193ms、548ms——持平（新交互都懒加载，没进首屏）
- 单独跑：冷启动 191ms，4× 降速 564ms；1000 穗离线搜索最慢 17.1ms；瀑布流 / 时间线 / 列表滚动 60fps、0 卡顿；完整备份 638ms，JS 堆 +15.6MB（三次中位）
- 首屏 JS 547.0KB（gzip 184.6KB，预算 585.9KB）

**没做 / 已知问题**
- 0415 系统字体放大 1.3 倍不破版：安卓 WebView 的 textZoom 要真机调，留到之后
- 0402 桌面三栏、0404 交互式首启引导、0408 待嫁接篮（同组 M，下一包再做）
- 0406 的 Ctrl+N 在浏览器里可能打开新窗口（浏览器保留快捷键），桌面版不受影响
- 没在真机上验证：安卓边到边与键盘抬升（OriginOS / 不同 WebView 版本）、状态栏图标深浅、长按震动、Windows 标题栏随主题、Windows 文件拖进窗口
