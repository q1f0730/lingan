## 拾穗 · Glean v0.11.0 — 一次三枝

*Three branches from one graft.* 点一次「嫁接」，按四步长出 **3 根并排的新枝**，三根用的变形法两两不同。

**下载**：安卓 `Glean_0.11.0_android.apk` · Windows `Glean_0.11.0_x64-setup.exe`（或 `.msi`）

**新功能**
- 四步嫁接：找张力（4 个）→ 撒八粒种子（反转 / 换媒介 / 撞年代 / 拿掉最显眼的 / 换尺度 / 材料限制 / 换视角 / 保留瑕疵，各一粒）→ 换掉最相像的三粒 → 留下三根最不一样的
- 每根新枝写清：用了什么变形、和另外两根哪里不同、一个 20 分钟内能做完的小实验；三根共同避开的套路单独列出
- 「看看它们是怎么长出来的」：展开能看到 4 个张力、8 粒种子，哪几粒被换过、哪三粒长成了新枝
- 等待时三根麦子在纸上慢慢长高，四步依次亮起；可以「先不等了」。系统开启「减少动态效果」时是一帧静图
- 新枝页按「同一次嫁接」收成一捆，一键「三根都收藏」
- 嫁接页「几穗」可以选到 4 穗
- 没配 AI 时，离线嫁接同样走四步、同样出三根

**为免费模型做的事**
- 四步压成 2 次调用（第 1 次找张力 + 撒种子，第 2 次换种子 + 收拢），适合智谱 glm-4.7-flash 这类有限流的免费模型
- 遇到限流（429）、网络抖动或回答没长全会自动退避重试，界面上会说「田里有点挤，几秒后再试一次」
- 第 2 次调用实在失败时，用第 1 次的八粒种子在本地收拢，仍然给出三根
- 模型给的三根里变形法撞了，自动换成剩下的种子，保证三根两两不同

**升级说明**
- 数据原样保留；以前的单根新枝照常显示

**修复**
- 请求出错时能区分限流、网络和密钥问题
