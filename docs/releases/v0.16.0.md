## 拾穗 · Glean v0.16.0 — 极简建筑工作室视觉

整体换皮：白纸黑字的编辑部目录。界面只剩字号、留白和一条线，颜色只来自你自己的照片。旧的暖纸、ASCII 麦田、动态麦田、衬线体、暗房风格连同它们的素材和样式全部撤掉。所有功能都还在，数据不动。

**下载**：安卓 `Glean_0.16.0_android.apk` · Windows `Glean_0.16.0_x64-setup.exe`（或 `.msi`）

**新的样子**
- 只有黑、白、灰；无圆角、无阴影、无描边卡片、无装饰图标，导航全是文字
- 字体换成 Inter + 思源黑体（自托管、按需子集化）；书名统一加书名号，《一一》不会再被看成破折号
- 每页一个超大标题带真实计数：穗仓 (n)、新枝 (n)、嫁接 (n)；计数就是真实条数，不出现假统计、百分比和图表
- 动效只剩两种：进入视口淡入、照片悬停 / 长按时慢慢放大 3%；系统开启「减少动态效果」时全部关闭
- 白 / 黑两套主题：设置 → 外观 → 跟随系统 | 白 | 黑（原来固定「夜晚」的自动换成黑）
- 手机：顶部只有 logo 和「设置」，底部常驻「随手拾一穗」速记栏 + 五个文字导航
- 电脑（≥1024px）：真正的多栏桌面布局——12 列栅格、顶栏中间导航、右侧速记输入，没有底部固定栏；详情左图右信息，嫁接左边已选、右边三根新枝并排

**每一页都换了**
- 穗仓：网格 | 列表 | 时间线 | 月历 文字切换（记住你上次选的）
  - 网格：4:5 图块，照片满铺 + 底部压暗小字说明；摘抄、想法、链接是浅灰色块
  - 列表（新视图）：无线表格（穗 / 类型 / 来源 / 标签 / 日期），桌面悬停行标题右移、光标旁出预览图
  - 时间线：按周成带，左边周标和条数，右边当周每穗的时间、标题、缩略图
  - 月历（由热力图衍生的新视图）：当月有穗的日子是黑格，点一天列出那天的穗；不算分数、不算连续天数
  - 搜索：命中字黑底白字，结果分「穗 (n)」和「新枝 (n)」（新枝也能搜了）
  - 按类型 / 标签筛选带真实计数，标签筛选时大标题变成「#夜里 (3)」
- 每日一穗：紧凑地放在网格上方，「拿去嫁接这 4 穗 / 放下」
- 速记展开、详情（照片 / 电影 / 歌 / 摘抄 / 想法）、编辑：整页覆盖、无线信息表；详情里新增「长进了这些新枝」（来源反查）、摘抄可「复制原文」、编辑页底部「删除这一穗」
- 嫁接：已选的穗是带细体序号的表格；嫁接中是「找张力 → 撒种子 → 换掉相像的 → 留三根」四步纯文字（完成 / 进行中），没有进度条；三根新枝 01 02 03，每根「因为这几穗」小图块可点回原穗、正文提到的穗可高亮，动作「留下 / 再接一次 / 复制 / 不要」
- 新枝：按批次成捆，行内展开详情（证据不足黑标、20 分钟小实验）；新增「宣言」视图——黑主题大字，一次一根，提到的穗用细体，底部 01 02 03 翻页
- 口味：一句开头判断 → 「倾向 / 来自这些穗」两列无线表格 → 构成、最近 7 天、常客、年代 → 新增「最近冷下来的」→ 灰阶的 365 天拾穗日子 → AI 侧写
- 设置：AI 服务（方块单选）、向量、外观、备份与导入（本机 n 穗 · n 新枝 · n 张图）、搬去 Obsidian、关于；手机上顶部是分组目录，电脑上左侧固定目录
- 引导（新）：第一次打开时三屏——拾穗是什么 / AI 只用你的素材（四条承诺）/ 选一个 AI 服务（可直接填 key，也可「先不用 AI，只收集」）；老用户升级不会看到
- 空状态、离线（顶部黑条）、删除确认弹层（替代系统弹窗，会说明它是几根新枝的来源）、删除后 5 秒内可撤销的 toast（带倒计时细线）、剪贴板提示黑条
- 托盘菜单改成文字分组：随手拾一穗 Ctrl+Shift+L / 打开穗仓 / 今日一穗 / 设置 / 退出拾穗；Ctrl+Shift+L 唤出的全局速记改成小窗样式（大号输入、自动识别类型可改、回车即存、Esc 收起）

**没有变的**
- 新枝来源溯源、证据不足、四步嫁接、离线嫁接
- 虚拟滚动、缩略图、objectURL 回收（网格图块固定 4:5，估高即准）
- 快捷键（N 速记展开、Ctrl+Shift+L）、托盘、安卓分享进来、剪贴板一键收
- 示例池与「清掉示例 / 换一批」、每日一穗、搬去 Obsidian、JSON 备份
- 数据库没有改结构（Dexie 仍是 version 4，无需迁移）；设置里旧的「时段配色 / 麦田静止」自动换成新的主题设置

**性能（InstaBox，1000 穗含 300 张照片，与换皮前 v0.15 同机对比）**
| | v0.15 | v0.16 |
|---|---|---|
| 冷启动（中位数） | 197 ms | 163 ms |
| 冷启动，CPU 降速 4 倍 | 572 ms | 460 ms |
| 网格滚动 | 60 fps，掉帧 0%，最多挂 20 张 | 60 fps，掉帧 0%，最多挂 22 张 |
| 时间线滚动 | 60 fps，掉帧 0% | 60 fps，掉帧 0% |
| 列表滚动（新） | — | 60 fps，掉帧 0%，最多挂 58 行 |
| 网格滚动，CPU 降速 4 倍 | 60 fps，掉帧 0% | 60 fps，掉帧 0% |

字体包：思源黑体只保留 400–700 字重轴 + 常用 3000 字分 7 片按需加载，加 Inter 拉丁 34KB，共 0.93MB（换皮前衬线 + 拉丁 + 等宽共约 0.97MB）。

**测试**
- 单测 129 条：删掉随旧风格一起移除的麦田 / ASCII / 时段配色 / 解码动效测试，新增书名号与摘抄出处、按周分组、月历、搜索高亮、标签计数、来源反查、主题与旧设置迁移、删除可撤销（原图一起回来）
- e2e 全部改到新界面（选择器失效的都改了测试，没有删）：每页检查无 canvas、无装饰图标、无圆角无阴影、字体是 Inter + 思源黑体；手机 / 桌面布局各自正确；确认弹层与撤销；列表 / 时间线 / 月历条数与库一致；新枝宣言黑底；减少动态效果时淡入关闭；新增引导与全局速记小窗用例；1000 穗性能测试加上列表视图
