## 拾穗 · Glean v0.12.0 — 新枝溯源

*Every branch knows where it grew from.* 每一根新枝下面都有一排「因为这几穗」，点一下就回到长出它的那一穗。说不清来源的新枝，会老老实实标上「证据不足」。

**下载**：安卓 `Glean_0.12.0_android.apk` · Windows `Glean_0.12.0_x64-setup.exe`（或 `.msi`）

**新功能**
- 因为这几穗：每根新枝底部一排小穗卡（3–5 件），图片穗带缩略图，其他穗是一枚小小的字印；点一下直达那一穗的详情
- 正文里点到名字的穗会轻轻描上麦金色；电脑上鼠标悬停、手机上点一下或长按，对应的那张穗卡一起亮起来
- 新枝页里展开任何一根，也能点回它的穗
- 嫁接改为至少 3 穗（可选 3 / 4 / 5 穗），「今日两穗」改为「今日三穗」；从一穗出发「以此嫁接」时会自动再抽两穗凑齐

**AI 不再「假装有出处」**
- 嫁接时每件穗都带着它在穗仓里的真实 ID 交给模型，模型必须用这些 ID 说明每根新枝用了哪几穗
- 有新枝没写 ID、不够 3 穗或写了不存在的 ID：自动重长一次，界面上会说「有一根说不清从哪几穗长出来，让它重长一次」
- 重来一次还是不行：这根新枝标「证据不足」，写明原因（比如「模型没说它从哪几穗长出来」），不会再悄悄替它补上来源
- 离线嫁接与本地收拢的新枝同样带来源，而且正文就是用这 3 穗写出来的

**升级说明**
- 数据库升级到第 2 版，自动迁移：以前的新枝全部保留，补上能点回的穗；早先只用 2 穗长出的新枝会写明「这根是早先长的，只记得这 2 穗」
- 导入旧备份时同样会迁移；备份里缺了某一穗时，其余几穗仍然对得上

**修复**
- 模型引用了越界的素材编号时，以前会被悄悄换成前几穗，现在如实标出
