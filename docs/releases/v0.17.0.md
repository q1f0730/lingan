## 拾穗 · Glean v0.17.0 — 秒搜

搜索重做了：本机建了一份全文索引，打一个字就出结果，命中的字黑底白字。类型、标签、日期范围可以叠在一起筛，新枝也一起搜。全部在本地完成，断网照样能用。

**下载**：安卓 `Glean_0.17.0_android.apk` · Windows `Glean_0.17.0_x64-setup.exe`（或 `.msi`）

**新功能**
- 输入就出结果：不用按回车，也没有防抖延迟。超大查询行后面跟着真实计数，例如「窗 (6)」，下面一行写着「在 n 穗和 n 根新枝里找到 n 处」
- 中文、英文分开处理：
  - 中文按「单字 + 相邻两字」建索引。搜两个字以上时这几个字必须连在一起出现，「晨雾」不会命中「早晨起了大雾」
  - 英文按词建索引，查询时按词首匹配，大小写不敏感：搜 `stack` 能找到 *Re: Stacks*，搜 `bon` 能找到 Bon Iver
  - 输入多个词（用空格隔开）时，每个词都要命中，每个词各自高亮
- 搜得到的字段：标题、作者、年份、正文 / 摘抄、为什么、标签、图片描述、链接；新枝搜标题、正文、嫁接点、形式、第一步、小实验
- 结果里能看到在哪儿命中：手机版每条结果有缩略图、标题、命中片段（例如「为什么「…玻璃窗里只有店员一个人」」），加上「类型 · 日期」。电脑版是无线表格，列为 穗 / 类型 / 命中 / 日期，鼠标悬停时该行底色变浅灰，光标旁出预览图
- 三行文字筛选，可以叠加：
  - 类型：全部 / 音乐 / 电影 / 图片 / 文案 / 链接 / 想法 / 新枝。每项带当前结果里的真实条数
  - 标签：当前结果里最常见的 12 个标签
  - 日期：不限 / 近 7 天 / 近 30 天 / 今年 / 自定（起止日期，结束那天整天都算）
  - 不输入关键词、只用筛选也可以
- 新枝结果：显示标题、命中的那段正文和日期，点一下跳到新枝页并展开那一根
- 「最近搜过」：最多记 6 个，点一下重搜，可以清空
- 没找到时会给提示：长词拆成单字，再加上常用标签，例如「没找到？试试「雾」「夜」」
- 电脑上在穗仓按 `/` 或 `Ctrl+K` 直接打开搜索，`Esc` 退出

**索引怎么维护**
- 新增一张 Dexie 表 `ftidx`，数据库升到 version 5。升级时不改动任何旧数据。打开 App 后在空闲时分批给已有的穗和新枝补索引（1000 穗约 0.1 秒）。补完之前搜索结果也是完整的，没进索引的条目会直接逐条比对
- 增量维护：新增、编辑、删除、撤销删除、导入、自动补图片描述、清掉示例，任何一种写入都会触发，只重切变动的那一行。只是打开看看（碰了一下）不会重切
- 再次打开 App 时直接读入已有索引，不重新切词（1000 穗读入 14–15ms）
- 清空全部时索引一起清掉；JSON 备份和搬去 Obsidian 不受影响

**界面**
- 沿用 v0.16 的 Studio 视觉，对照 m18（手机）和 d8（电脑）搜索稿：查询行下一条 1px 黑线，筛选是文字加下划线，命中字黑底白字，无圆角、无阴影、无图标。结果区每次敲字直接替换，不做淡入

**性能（InstaBox，1000 穗含 300 张照片，断网；两次完整 e2e 的结果，原始数据 docs/perf/v0.17.0.json）**
| | v0.17 |
|---|---|
| 搜两个汉字：从输入到结果（含高亮）画到屏幕上 | 16.7–17.9 ms（黄昏 / 海边 / 钢琴 / 夜车 / 麦田，每次 63–178 条结果） |
| 其中搜索计算本身 | 0.4–1.6 ms |
| CPU 降速 4 倍（模拟中端安卓） | 30.7–47.0 ms |
| 旧库升级后补 1000 穗索引 | 75–82 ms（后台分批，不挡首屏） |
| 再次打开时读入索引 | 14–15 ms，不重新切词 |
| 冷启动（中位数） | 173–210 ms（4 倍降速 488–519 ms；v0.16 为 163–186 / 460–541 ms，同一量级） |
| 网格 / 时间线 / 列表滚动 | 60 fps，掉帧 0% |

17ms 左右基本就是「下一帧就出结果」：测量里包含了等待那一帧绘制的时间。

**测试**
- 单测 146 条（新增 17 条，在 src/__tests__/search.test.ts），覆盖：切词（单字、二元、英文整词、全角转半角）、连续出现才算命中、英文词首前缀、多个词同时命中、排序、索引缺失或过期时结果不变、高亮与片段、新枝搜索、1000 条计算耗时、日期范围、最近搜过、v4 → v5 升级不丢数据并后台补索引、增删改穗与新枝时增量更新
- e2e：
  - 每个查询的结果数都和 e2e 按同一规则直接读库数出来的完全一致
  - 筛选叠加：类型 / 近 7 天 / 自定日期 / 标签
  - 断网搜索；没找到时的提示；点结果打开详情；「最近搜过」
  - 新枝搜索后点进去会展开那一根
  - 刚用速记存的穗马上搜得到，而且已经写进索引表
  - 一整轮增删改之后，索引表和穗、新枝一一对应
  - 旧库（v1 / v2）升级到 version 5 后，旧穗和旧新枝都搜得到
  - 1000 穗断网搜两个汉字，断言输入到画出结果 ≤ 100ms

**已知限制**
- 中文只按字面匹配：不分词，不做同义词，也不做繁简互通（搜「雾」找不到「霧」）
- 英文只按词首前缀匹配：搜 `tacks` 找不到 Stacks
- 图片里的文字还搜不到（路线图 v0.30）
