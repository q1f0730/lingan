## 拾穗 · Glean v0.41.0 — 找得到 · 逛得开

这一版让穗仓「找得到、逛得开」：搜「花样年华」也能找到「花樣年華」；没搜到时直接告诉你该放宽哪个筛选，或者一键把这句拾进来；搜出来的结果可以当场挑几穗去嫁接，一组好用的筛选能存成会自己长的「智能穗束」；秒搜里打 > 是命令面板，电脑上速记小窗里打 ? 就能搜。详情页多了「漫步」，从一穗走到和它最相关的下一穗；口味页会指出你几乎没收过的类型、年代和情绪——只提示、问一句，不替你去网上找东西。另外修了 v0.40 遗留的「手机刚打开就长按卡片没反应」。

**下载**：安卓 `Glean_0.41.0_android.apk` · Windows `Glean_0.41.0_x64-setup.exe`（或 `.msi`）· 浏览器扩展 `glean-extension.zip` · Agent 桥 / 命令行 `glean-mcp.mjs` · 校验 `SHA256SUMS.txt`

**升级**：Windows 装着 v0.25 – v0.40 的会自动收到（更新前先自动备份）；安卓 v0.26 起可以在 设置 → 更新 里直接「下载并安装」。数据库不变（仍是 Dexie v12），不用迁移；智能穗束只存在这台设备上（本机设置，不进同步）。

**做了哪些（编号见 docs/ideas/ideas.csv）**

找得到
- **0134 繁简互搜**：搜索框里一出现汉字，就同时按全简体和几种繁体写法再找一遍（一简多繁时最多 6 种组合），命中字照样高亮。不改索引、不碰数据；字表约 10KB（来自 OpenCC，Apache-2.0），只在第一次打汉字时下载
- **0428 没结果时的下一步**：「没找到这一穗」下面一条一个按钮——「不限类型（现在：电影）」「不限标签」「不限日期」「去掉语法筛选」；再给一个「把「这句话」拾进来」，点了就存成一穗，结果里马上出现
- **0133 你忘了你收过**：搜出来的穗里有 300 天以前收的，结果上方轻轻提一句「你 2 年前收过「花樣年華」，还记得吗？」，点一下打开
- **0137 命令面板**：秒搜（/ 或 Ctrl+K）里以 > 开头就变成命令：去穗仓 / 嫁接 / 新枝 / 作品 / 口味 / 设置、拾一穗（完整表单）、问穗仓、随便翻一穗、找还没写为什么的穗、打开某个智能穗束；↑↓ 选，回车执行，中英文关键词都认（>set、>设置）
- **0138 速记小窗里也能搜**：电脑上 Ctrl+Shift+L 唤出的小窗，输入 ? 开头就在小窗里秒搜（标题 / 作者 / 句子 / 为什么 / 标签，繁简互通，最多 6 条），↑↓ 选、回车打开详情；? 开头的字不会被存成穗

逛得开
- **0136 搜索结果一键嫁接**：结果区「挑几穗去嫁接」，点结果挑 3–5 穗（挑的时候点不会打开详情），「嫁接这 n 穗」直接带进嫁接页
- **0128 智能穗束（保存的筛选）**：搜索框下「存成智能穗束」把当前的查询连同类型 / 标签筛选存下来；打开秒搜还没输入时列出来，每个带实时条数——以后收的穗对得上也会算进来；× 删掉
- **0132 漫步**：详情里「走到最相关的下一穗 →」：先走连线（两头都算），再走同一部作品、一起被嫁接过的、意思相近的，都走过了就随便走一穗；这一趟走过的不再走，显示「从上一穗走来：连线 · 像」和第几步，可以「从这里重新走」
- **0436 穗仓全键盘**（电脑）：J / K 在卡片间移动，Enter 打开，G 放进 / 拿出嫁接篮，E 编辑，Del 删除；在输入框里打字、有弹层或在秒搜里时不接管
- **ROADMAP v0.41 穗仓的空地**：口味页新一栏，最多三条：还没收过 / 很少收的类型（「你还没收过链接穗。」）、前后都有中间整十年空着的年代、「为什么」和标签里一次都没出现过的情绪（温暖 / 难过 / 好笑 / 燃 / 不安 / 心动）。每条只有一句提示和一个问题（「上一次笑出声是因为什么？」），不出现任何外部推荐内容，满 10 穗才出现

修 v0.40 遗留
- **手机刚打开就长按一张卡没反应**：长按菜单是空闲后才加载的，以前在它加载完之前按住，这一下谁都不管——菜单不出来，松手还会当成一次点击打开详情。现在和 v0.40 修右键一样：菜单还没就绪时由 App 先计时，到点记下是哪一穗，菜单一到就补开底部菜单（只开一次），松手不进详情。复现：把菜单块拖慢 2.5 秒后长按，旧版 3 次都没菜单、反而打开了详情；新版 3/3 出菜单、0 次误开详情（e2e v040 组新增同样用例，用真实触摸事件）

**性能**：（1000 穗，同一台测试机同一会话交替 9 轮，首帧画完的中位数）冷启动 v0.40 188ms → v0.41 190ms，4 倍降速 565 → 552ms，都在误差内（性能回归门 OK）；秒搜 ≤18.4ms，滚动 60fps，备份 1000 穗 / 300 图 653ms。首屏 JS 539.0KB（+1.9KB）、首屏 CSS 118.5KB、首片字体 286.0KB 不变，总资源 2217.8KB（预算 2226.6KB 不放宽）。详见 docs/perf/v0.41.0.json。

**已知问题 / 没有真机验证**
- 繁体字不在应用内置的中文字体切片里，显示靠系统字体（和以前一样）；繁简转换按单字对照，个别一简多繁的词（如「头发 / 頭髮」）只列前几种组合
- 穗仓全键盘按页面上卡片的先后顺序移动，瀑布流里和视觉上的左右顺序可能不完全一致
- 手机长按修复在 Chromium 触摸模拟下验证，没在 vivo 真机上测
