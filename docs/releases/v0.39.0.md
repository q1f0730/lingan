## 拾穗 · Glean v0.39.0 — 外面的东西拾进来 + 隐私边界

这一版把「外面的东西」接进来，同时把门看紧：收公众号 / 网页链接时顺手把正文存成本地快照，原文删了也能看；断网时收的链接打「待补」，网一回来自动补上；网易云歌单粘个链接整单拾进；RSS / RSSHub / Letterboxd 订阅进单独的「待拾」，你写一句为什么才算一穗。另一边：心事可以上锁（本机 PIN），每一穗可以单独决定给不给 AI / Agent / 分享 / 花园，每一样会往外连的接入都写清楚读什么、写什么、只连哪些域名，并且能一键停用。

**下载**：安卓 `Glean_0.39.0_android.apk` · Windows `Glean_0.39.0_x64-setup.exe`（或 `.msi`）· 浏览器扩展 `glean-extension.zip` · Agent 桥 / 命令行 `glean-mcp.mjs` · 校验 `SHA256SUMS.txt`

**升级**：Windows 装着 v0.25 – v0.38 的会自动收到（更新前先自动备份）；安卓 v0.26 起可以在 设置 → 更新 里直接「下载并安装」。数据库不变（仍是 Dexie v12），不用迁移：穗多了几个不加索引的字段——正文快照 `snap` / `snapAt`、上锁 `locked`、关掉的出口 `shut`（这几个随备份和同步走），以及只在本机的「待补」`metaTodo`（不同步、不算修改）。订阅和待拾放在独立的 IndexedDB `glean-feed`，不同步、不进备份。

**做了哪些（编号见 docs/ideas/ideas.csv）**

外面的东西拾进来
- **0017 / 0829 链接正文快照**：收链接时顺手把正文抽成纯文本存进穗里（≤50KB，不切断字）+ 正文第一张像样的图，原链接失效也能看；用的就是抓标题封面时那一份网页，不多发请求。详情页「正文快照 · 存于 日期」点开看；已有的链接穗可以点「存正文快照」补。设置 → 极速采集「收链接时存正文快照」可关。抽正文是够用版 Readability：先认公众号 #js_content、`<article>`、articleBody、*-content、`<main>`，都不像就退回所有 ≥20 字的段落
- **0013 / 0827 公众号文章**：认出 mp.weixin.qq.com 链接，读页面脚本里的标题 / 公众号名（记成作者）/ 封面 / 摘要 / 发布时间，正文取 #js_content 存快照；文章被删、违规、要验证时给能看懂的原因
- **0054 待补**：断网或超时没读到的链接打「待补」角标，联网（online 事件）或下次启动空闲时自动重试，补上标题 / 封面 / 快照后去掉角标；网页本身说不行的（404、删了）不再重试。只有本机有待补时才加载重试模块
- **0015 / 0801 网易云歌单整单拾进**：设置 → 备份与导入 →「网易云歌单」，粘贴歌单链接或整段分享文案（`/#/playlist?id=`、`/playlist?id=`、`/m/playlist?id=`、`/playlist/123/` 都认），读公开接口拿全部曲目（前一批 + 剩下的按 500 首一批补），预览里勾选，导成每首一穗（标签 = 歌单名、为什么留空待补）或整单一穗，放进穗束「歌单 · 名字」；可选在后台补专辑封面；导入前自动快照，已有的歌跳过
- **0804 订阅进「待拾」**：设置 →「订阅 · 待拾」加 RSS 2.0 / RSS 1.0 / Atom 源，每天最多自动拉一次（也可以「现在拉」）；新条目只进「待拾」，穗仓顶部一条「待拾 n」点开看：只有标题和一行摘要，左滑 / 「丢」= 不要（以后也不再出现），右滑 / 「拾」= 必须写一句为什么或至少一个 #标签 才进穗仓
- **0826 RSSHub 路由模板**：B 站 UP 主投稿、微博博主、小宇宙播客、豆瓣用户广播、知乎专栏，填 id 即生成订阅地址；RSSHub 实例可以换成自部署的
- **0847 Letterboxd**：填用户名直接订阅 `letterboxd.com/用户名/rss/` 观影日记
- **本机小模型国内镜像**：时区是中国大陆时，模型下载先走 cdn.jsdmirror.com → jsd.onmicrosoft.cn → fastly.jsdelivr.net → cdn.jsdelivr.net → gh-proxy.com → GitHub raw（2026-11-04 用阿里云 7 个大区 × 移动 / 电信 / 联通拨测排的序：前两个是国内节点、三网都通；cdn.jsdelivr.net 移动基本不通，raw 移动全挂）；其它地区仍是 jsDelivr → raw，再试国内镜像。地址都指 v0.38.0 tag 下的同一个文件，下完照样核对 SHA-256，第三方镜像换不了包

隐私边界
- **0907 敏感穗上锁**：设置 →「上锁」设一个 4–12 位数字 PIN（PBKDF2-SHA256 12 万次加盐，只存这台设备，不同步、不进备份；输错 5 次等 30 秒）。详情里「上锁」后，没解锁时穗仓 / 列表 / 时间线只显示「上锁的一穗」（只剩类型和时间），秒搜、口味、母题 / 星图、每日一穗都看不到；解锁 5 分钟，切到后台立刻重新锁上。不管解没解锁，上锁的穗永远不进分享、花园、Agent / MCP、任何模型（连本机模型也不发）。这是「防随手翻 + 防外发」的帘子，不是加密：库本身仍是本机明文（同步时照常端到端加密）
- **0934 每穗出口**：详情底部「给谁看」：AI / Agent·MCP / 分享 / 花园 四个出口各自开关，关了的出口永远拿不到这一穗；设置 → 接入与权限 →「按标签设出口」可以一次给某个标签下的穗关 / 开某个出口（比如 #心事 不给 AI）。上锁 = 四个全关。拾穗没有第三方插件市场，「插件」出口就是 Agent / MCP
- **0805 接入的权限清单与一键停用**：设置 →「接入与权限」列出每一样会往外连、或会读写穗仓的接入（抓链接与快照、订阅、网易云歌单、本机小模型下载、AI 服务、Agent 与 API）：读什么、写什么、只连哪些域名。运行时在发请求前把关：停用了就拒绝，域名不在声明里也拒绝（出站总开关仍在更外一层）。可以逐个停用，也可以一键全部停用，只在这台设备上

顺带
- **0415 系统字体放大 1.3 倍**：e2e 新增 360 宽手机、每个元素字号 ×1.3（模拟安卓 WebView textZoom）跑穗仓 / 嫁接 / 新枝 / 作品 / 口味 / 设置 / 详情，全部不横向溢出
- 速记表单草稿：页面被关 / 切到后台时立刻写下还没写的草稿（之前只在表单关掉时写，刚打完半秒内 App 被杀会丢；速记条早就是这样）
- e2e：v0.38 的向量组之前被误放在 `E2E_ONLY=v037` 的分支里、整套跑时没跑到，这版挪回主序列（固定在境外时区测 jsDelivr → raw，国内镜像在 v0.39 组测）

**性能**（docs/perf/v0.39.0.json，1000 穗，同一台测试机同一会话交替 9 轮 painted 中位数）：冷启动 v0.38 187ms → v0.39 192ms，4× 降速 581 → 586ms，Mann-Whitney 都不显著，持平（性能回归门 OK）。e2e 单跑：冷启动 188ms / 4× 535ms，搜索 ≤17.1ms，速记回车→卡片中位 10ms，滚动 60fps 无掉帧，备份 638ms。首屏 JS 530 → 535.6KB（接入把关和上锁状态要在首屏，其余全懒加载），总资源 2222.0KB（预算 2226.6KB 不放宽）。

**没做 / 放弃**
- **指纹 / Windows Hello 解锁**：要真机接系统生物识别接口（安卓 BiometricPrompt、Windows Hello），这版没做，上锁只有 PIN
- **网易云「只要我红心的」**：红心歌单（我喜欢的音乐）默认不公开，读它要登录网易云；拾穗不碰你的网易云账号，所以只能读公开歌单——把「我喜欢的音乐」设成公开后粘它的链接就能整单拾进

**已知问题 / 没有真机验证**
- 网页版浏览器跨域读不了公众号 / 网易云 / 大多数 RSS（App 内走系统网络才行）；e2e 用模拟接口测
- 公众号常要「环境异常 / 去验证」，这时只存链接并打待补，不会绕过验证
- 正文快照是纯文本，不存排版和正文里的其它图片
- 忘了 PIN 可以直接重设一个新的（上锁的穗仍然上锁，用新 PIN 打开）——所以 PIN 防的是别人随手翻和所有外发，拿着你解锁的手机的人也能重设；PIN 不跟着同步，另一台设备要自己设
- 字体放大是模拟测的，没在真机系统字体 1.3 倍下截图
- 国内镜像是第三方服务，排序按 2026-11-04 的拨测，以后可能变
