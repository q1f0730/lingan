## 拾穗 · Glean v0.45.0 — 到点递一穗 · 给未来的穗

这一版让拾穗会自己「回来找你」，但不吵：设一个时间（默认晚上 21:30），到点用系统通知递来今天的一穗，点一下直接打开今日卡；想要的话同时推到微信（Server酱）。任何一穗都可以「封存到某天」——一个月、半年、一年后，或自己挑日子，到期前它不在穗仓里出现，那天会收到一封「给未来的穗」。打开 App 时还会安静地出现一年前的今天收的那一穗、停了 7 天的作品，以及几穗还没写为什么的——都只是一张卡，不推送。电脑上打游戏 / 演示 / 开专注助手时，剪贴板、截图提示和到点通知都先憋着。

**下载**：安卓 `Glean_0.45.0_android.apk` · Windows `Glean_0.45.0_x64-setup.exe`（或 `.msi`）· 浏览器扩展 `glean-extension.zip` · Agent 桥 / 命令行 `glean-mcp.mjs` · 校验 `SHA256SUMS.txt`

**升级**：Windows 装着 v0.25 – v0.44 的会自动收到（更新前先自动备份）；安卓 v0.26 起可以在 设置 → 更新 里直接「下载并安装」。数据库不变（仍是 Dexie v12），不用迁移。

**做了哪些（编号见 docs/ideas/ideas.csv）**

到点递一穗（ROADMAP v0.33）
- **到点递一穗**：设置 → 到点递一穗，开关 + 时间（默认 21:30，默认关）。电脑由托盘常驻的拾穗发系统通知（过点 3 小时内补递，一天只递一次）；安卓用系统闹钟定时（不精确窗口 10 分钟、不要精确闹钟权限），App 不在前台也能收到，开机 / 更新后自动重排；点通知直达今日卡。通知只写标题级信息：私密 / 上锁的穗、或设了上锁 PIN 时只说「一穗」
- **0839 同时推到微信（Server酱³ / Server酱 Turbo）**：设置里填 SendKey（进系统钥匙串，不进设置文件），只推标题 + 一句 + glean:// 链接，正文不外发；地址在出站白名单里，认不出的 Key 不发
- **0843 补一句为什么**：拾进来 24 小时后还没写为什么的，最近的最多 3 条汇总在穗仓顶部的回看卡里；到点通知里顺带说「还有 n 穗没写为什么」（可关）
- **0528 让提醒更准时（vivo）**：vivo / iQOO 机型在设置里多一个入口，一键跳到自启动 / 后台耗电设置，跳不过去就打开应用详情页

给未来的穗
- **0924 封存到某天**：卡片菜单「封存到…」→ 一个月后 / 半年后 / 一年后（月底落到月末）/ 自己挑日期（明天起、10 年内）。封存中不出现在穗仓、搜索、每日一穗、嫁接里，穗仓顶部只显示「封存中 n 穗 · 最早 x 月 x 日拆开」；到期那天穗仓顶部来一封信，拆开才回来
- **0942 一年前的今天**：打开 App 时安静出现一张卡（同月同日、早于今年），不推送；上锁 / 放下 / 示例 / 封存中的不算
- **0311 作品停了 7 天轻推一次**：7 天没动的作品在穗仓顶部的回看卡里提一句「《X》停了 n 天，补一穗？」；同一段停顿看过就不再提，完成的不提

电脑与入口
- **0550 全屏时不打扰**：Windows 上全屏应用 / D3D 独占全屏 / 演示模式 / 专注助手期间，剪贴板提示、截图提示和到点递一穗都先不弹，退出后照常
- **0545 一套深链**：托盘、通知、快捷方式都只造 `glean://go/…` 地址，前端一个解析器路由（今日一穗 / 穗仓 / 设置 / 秒搜都由单测核对，e2e 断言 glean://go 落到正确页面）

修复
- **托盘「暂停剪贴板提示」菜单文字和状态对不上（v0.44 遗留）**：菜单文字只按状态算；暂停到点改按墙钟（睡眠 / 休眠期间也算时间），后台线程到点把文字改回来，期间又点过就不会改错

瘦身（预算不放宽）
- 懒加载块里的中文字符串构建时收成每块一个压缩包（GBK + deflate），运行时同步解开；拼音字表 / 繁简字表 / 示例池改成单独的 `.bin` 资源按需取（省掉 base64 的 1/3）。腾出的空间给了这一版的新功能，总资源 2221.6 / 2226.6KB

**还没真机验证**：安卓系统闹钟定时与 vivo 设置页跳转（Kotlin 编译检查 + 模拟桥）、Windows 全屏检测与托盘到点恢复（Windows 目标编译检查 + 模拟 Tauri 的 e2e）、Server酱真实推送（只测了地址与白名单）。
