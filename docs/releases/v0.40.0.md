## 拾穗 · Glean v0.40.0 — 时间与回看

这一版让拾过的东西「随时间说话」：周日一张周记卡、每月月初一捆上个月的麦捆（一月还有一年的麦田）、半年没碰的好东西提出来让你决定留着还是放下；同一穗可以隔段时间再看一句，满一年的穗会问你一句「现在的为什么」，和当时写的并排放。口味页不再数「连着拾了几天」，改成「本月有 n 天在拾」，考试周可以休耕；顶上多一句离线写的「口味会说话」，底下一条只记第一次的田埂。另外修了 v0.39 的「忘了 PIN 可以直接重设」，并先给安装包瘦了身。

**下载**：安卓 `Glean_0.40.0_android.apk` · Windows `Glean_0.40.0_x64-setup.exe`（或 `.msi`）· 浏览器扩展 `glean-extension.zip` · Agent 桥 / 命令行 `glean-mcp.mjs` · 校验 `SHA256SUMS.txt`

**升级**：Windows 装着 v0.25 – v0.39 的会自动收到（更新前先自动备份）；安卓 v0.26 起可以在 设置 → 更新 里直接「下载并安装」。数据库不变（仍是 Dexie v12），不用迁移：穗多两个不加索引的字段——「再看」`revisits` 和「放下」`down`，随备份和同步走；休耕、周记 / 麦捆收起、田埂开关只存在这台设备上。

**做了哪些（编号见 docs/ideas/ideas.csv）**

时间与回看
- **0922 / 0155 周日的周记**：周日（到周一）穗仓顶部一张「本周拾穗 · 周记」：7 天拾了几穗、最常出现的标签、几穗还没写为什么；点「写三句周记」才展开三问（本周最打动你的一穗？哪穗你现在不同意了？下周想多拾什么？），答了哪句存哪句，存成一穗带 #周记 的想法；「这周不写」就收起
- **ROADMAP v0.37 月度麦捆 + 一年的麦田**：每月 1–7 号一张「上个月的麦捆」：拾了几穗、几天在拾、最常在哪个时段收（凌晨 / 早上 / 中午 / 下午 / 晚上 / 深夜）、长出几根新枝、最意外的一根（和已有新枝最不像的那根）；一月那张多一行「一年的麦田」：全年穗数 / 天数 / 新枝 / 最常出现的标签。数字和口味页热力图同一个口径（不算「我讨厌的」和上锁的）
- **0925 被遗忘的好东西**：麦捆里固定一栏，半年以上没打开、没嫁接过的三穗（同一个月看到的是同三穗），每穗「留着」（半年内不再提）或「放下」
- **0938 放下（归档不删）**：详情里「放下」/「拿回来」。放下的穗不进默认穗仓和每日一穗，秒搜照样搜得到，筛选条多一个「放下的 (n)」
- **0131 再看一句**：详情「再看一句」，同一穗随时间攒下多段感受（只追加，原来的为什么不动），按日期列在为什么下面
- **0915 一年后再写一次为什么**：满一年、写过为什么的穗，打开详情直接问「一年了 · 现在的为什么？」；写下后「当时 / 一年后」两栏并排；口味页记「一年后重写过为什么的穗 n」
- **0923 本月有 n 天在拾 + 休耕**：口味页那行「连着拾了 n 天」换成「本月有 n 天在拾」（断了不清零）；「休耕 7 天」可以随时「结束休耕」，休耕的日子在热力图上是斜纹格，不算断
- **ROADMAP v0.35 口味会说话 + 0919 现在的我 vs 一年前的我**：口味页顶上一句离线写的话：「最近 30 天拾了 n 穗，X 最多；A、B 在升，C 淡了」（近 30 天 vs 前 30 天）；有两年数据时再加一句和一年前那一年比：留下的、新来的、不见了的标签。不用配 AI
- **0926 / 0939 田埂**：口味页底部一栏，只记「第一次」：拾下第一穗、第一次嫁接、第一次跨媒介嫁接、第一根做成的新枝、第一次立项、第一次改写一年前的为什么——一行字 + 日期 + 链接，不弹窗、没有积分和等级，可以整块关掉

修 v0.39 遗留
- **忘了 PIN 不能再一键重设**：两条路——① 「24 小时后重设」：申请后要等满 24 小时、再点一次「现在重设」才清掉旧 PIN；这期间上锁的穗照样锁着（PIN 也照样能开），随时可以「取消重设」。计时不直接信系统时间：App 开着时只认墙钟和单调钟里走得少的那个（把时间往后拨不算数），下次启动发现系统时间比见过的最晚时间还早（往回拨过）就从头算。② 「立即重设并清空上锁穗」：两次确认后，所有上锁穗的标题 / 正文 / 为什么 / 标签 / 图 / 再看全部清空，只剩空壳进回收站，再设新 PIN

瘦身（预算不放宽：先腾出约 54KB，加完这版新功能后总资源仍比 v0.39 少 34KB）
- 首屏 CSS：index.css 里 506 条被 rewamp.css 同一个选择器覆盖掉的声明、6 条没人用的选择器删掉；删前删后在手机 / 桌面 × 白 / 黑 × 11 个页面逐元素比对计算样式，没有差异。128.2 → 118.5KB
- 中文字体：切片时只留横排会用到的 OpenType 特性（ccmp / locl / kern / liga / calt / clig / mark / mkmk / halt / chws），不再把全角 / 半角 / 竖排 / aalt 的替换字形塞进首片；字的覆盖不变，新旧字体截图逐像素一致。首片 329.6 → 286.0KB
- 总资源 2222.0 → 2188.2KB（加完这版的新功能之后）

**性能**：见 docs/perf/v0.40.0.json（1000 穗，同一台测试机同一会话交替 9 轮 painted 中位数，性能回归门）。
