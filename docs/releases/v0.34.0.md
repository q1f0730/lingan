## 拾穗 · Glean v0.34.0 — 分享出去 · 隐私边界

这一版管「从拾穗往外发」的这条路：分享一穗或一根新枝时，你一项项勾要带什么（默认只带标题和正文），发出去前在本机扫一遍手机号、身份证号、邮箱和你自己填的敏感词；新枝可以画成一张 1080 宽的明信片发到微信 / 小红书；朋友也装了拾穗的话，「递一穗」会进他待理里单独一栏「别人递来的」；想公开的穗可以生成一个单文件的花园网页。设置里多了一个「出站总开关」，关掉以后拾穗不往外网发任何东西。

**下载**：安卓 `Glean_0.34.0_android.apk` · Windows `Glean_0.34.0_x64-setup.exe`（或 `.msi`）· Agent 桥 / 命令行 `glean-mcp.mjs` · 校验 `SHA256SUMS.txt`

**升级**：Windows 装着 v0.25 – v0.33 的会自动收到（更新前先自动备份）；安卓 v0.26 起可以在 设置 → 更新 里直接「下载并安装」。数据库不变（仍是 Dexie v12），不用迁移。

**做了哪些（编号见 docs/ideas/ideas.csv）**

分享
- **0899 分享时逐项勾选**：卡片右键 / 长按 →「分享…」，标题、正文、为什么、时间、来源链接、标签、来自哪个 App 一项项点；默认只勾标题和正文。下面那段灰底的字就是要发出去的全部内容，链接自动去掉追踪参数
- **0909 发出去前扫个人信息**：分享、明信片、花园生成前都在本机扫手机号、身份证号、邮箱，以及 设置 → 分享与花园 里你自己填的敏感词（真名、学校、宿舍地址……）。命中就先拦下，确认框里只显示打码后的样子（138****5678）。私密穗分享前也会再问一次
- **0916 新枝的「因为这几穗」可以打码**：分享新枝时选「显示 / 只写类型和标题 / 不带」，默认只写类型和标题；私密穗永远只写「一穗私密的」
- **新枝明信片**（ROADMAP v0.34）：新枝下「分享」→「生成明信片」，画成 1080 宽的竖版 PNG：标题、正文、形式、溯源穗、落款「— 公开名」。安卓「分享图片…」直接走系统分享面板，「存到相册」进 相册 / Glean；电脑上保存图片。图片是重新画出来的，原图的拍摄信息不会带出去
- **0900「别人递来的」**：分享面板里「复制递穗链接」会复制一段话加一个 `glean://capture?…&from=你的公开名` 链接。对方装了拾穗，点开链接或把整段话粘进速记条，这一穗进他 待理 顶上的「别人递来的」：写明谁递来的、不进穗仓、不算口味、不进嫁接；「也拾一穗」必须先写一句自己的为什么才进穗仓，「不要」直接丢掉。递来的只存在那台设备

花园
- **0902 花园只放标了「花园」的穗**：卡片菜单「放进花园 / 拿出花园」，多选工具条「放进花园」（可撤销）；私密穗放不进去。设置 → 分享与花园 →「生成花园页」，先把要公开的那些穗列一遍让你确认
- **0903 花园页清洗**：生成一个自带样式的单文件 `garden.html`（可以放到 GitHub Pages 之类的地方）。图片在 canvas 里重画再导出，拍摄信息 / GPS 全丢，最长边 1080；链接去追踪参数；只写到年月，不带来源 App、不带内部 id；「为什么」默认不带，可以勾上
- **0901 公开名默认 Q1f730**：分享署名、花园作者、明信片落款都用它，可以改

隐私边界
- **0905 出站总开关**：设置 → 出站 最上面。关掉后模型、看图、向量、抓链接、网盘同步、检查更新都停，Agent 写入也停；本机和局域网照常（本地模型、局域网直连还能用）。顶上的黑条写「出站已关」
- **0908 第三方 Token 本地加密存储**：AI 密钥、坚果云应用密码、同步数据钥从 v0.20 / v0.31 起就只在系统钥匙串里，不进 IndexedDB 和备份；这版核对了一遍，并补了回归测试：分享设置里的敏感词、别人递来的穗也只在本机，不进 .glean 备份、不同步
- **0910 数量不是成就 / 0911 核心永久免费 + 本地优先**：README 写明承诺（收、搜、嫁接、导出永远免费，数据在你自己的设备上；不做「拾满 100 穗」这类数量成就），AGENTS.md 里也写成了规矩

顺带
- 导航气泡、分段切换的滑块不再靠动画库的布局动画（那一块约 46KB），换成自己写的小滑块，看起来一样；安装包总资源比 v0.33 小约 19KB

**性能**：同一 InstaBox 会话交替 9 轮冷启动（画完首帧）v0.33 195ms / 4× 降速 564ms，v0.34 188ms / 588ms：普通略快、4× 中位慢 24ms，两项都在噪声内（Mann-Whitney 不显著）；定稿构建完整 e2e：冷启动 192ms（4× 520ms）、1000 穗搜索 ≤17.9ms、滚动 60fps 不掉帧、备份 97.5MB 608ms。首屏 JS 563.3KB（gzip 191KB），总资源 2217.6KB，比 v0.33 小约 19KB。

**已知问题 / 没有真机验证**
- 「递一穗」的 `glean://` 链接在微信里点不开（微信不放行自定义链接），要复制整段话粘进拾穗的速记条
- 没在真机上试过：安卓「分享图片…」发到微信 / 小红书、「存到相册」在 vivo 相册里的位置、明信片在 Windows 保存对话框里的文件名
- 还没做：0907 敏感穗上锁（要生物识别 / PIN，所有查询都要加过滤，留到后面一版带真机验证做）
