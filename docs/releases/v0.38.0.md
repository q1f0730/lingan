## 拾穗 · Glean v0.38.0 — 向量与关系：按意思找、看出母题、把穗连起来

这一版让穗与穗之间有了关系：搜「孤独」能找到为什么里写「一个人坐末班车」的那穗；口味页把你拾的东西按意思聚成几个反复出现的母题，还能展开一张星图，点两颗离得远的星直接去嫁接；同一部电影的剧照、台词、影评链接自动归成一部作品；你自己发现的「这两穗很像 / 反着 / 它引出了它」可以连上线。没配任何 AI 也能用：设置里可以下载一个 8.8MB 的本机小模型，断网照样算。

**下载**：安卓 `Glean_0.38.0_android.apk` · Windows `Glean_0.38.0_x64-setup.exe`（或 `.msi`）· 浏览器扩展 `glean-extension.zip` · Agent 桥 / 命令行 `glean-mcp.mjs` · 校验 `SHA256SUMS.txt`

**升级**：Windows 装着 v0.25 – v0.37 的会自动收到（更新前先自动备份）；安卓 v0.26 起可以在 设置 → 更新 里直接「下载并安装」。数据库不变（仍是 Dexie v12），不用迁移：穗多了两个不加索引的字段（作品归属 `work`、连线 `links`），随备份和同步走。

**做了哪些（编号见 docs/ideas/ideas.csv）**

按意思找
- **0109 语义搜索**：秒搜结果分两栏——「字面命中」和「意思相近」。查询也算一次向量，和穗仓里同一个模型算过的穗比余弦，字面已经命中的不重复列。用本机小模型或本机 / 局域网的 LM Studio、Ollama 时，打字停下就算；用云端向量接口时要点一下「按意思再找找」（免得每停一次就往外发一次，也不会每次都弹「发出去前看一眼」）
- **ROADMAP 端侧向量（原 v0.21）**：设置 → 向量 →「下载本机小模型」（约 8.8MB，下载前写明大小，可随时删）。没配向量模型时自动用它；新收的穗断网也能在几秒内拿到向量，私密穗也算（不出设备）。模型来自 minishlab/potion-multilingual-128M（model2vec 静态向量，MIT），裁到中文 19017 个 + 常用英文 / 数字 12000 个 + 标点 1500 个词元，int8 量化；推理是自写的 Unigram 分词 + 取平均，没有运行库、不需要 WebGPU / wasm，独立懒加载块约 2.8KB，模型存独立的 IndexedDB `glean-mini`。下载先走 jsDelivr、不通再走 GitHub raw，地址固定到 v0.38.0 tag，下完核对 SHA-256，不一致就丢掉
  - 原计划用 Transformers.js（运行库 + wasm 1MB 以上），体积预算放不下，改成了这个方案；效果比大模型粗，配了 bge-m3 之类的向量模型时优先用那个

看出母题
- **0106 母题聚类**：口味页新增「母题」：有向量（同一模型算过 ≥80% 的穗）就按向量聚，没有就按标签 + 为什么 / 标题里的二元字（TF-IDF）聚；3–15 个簇（√穗数），固定种子，同一批穗每次分得一样；簇名取簇里最有区分度的标签或词（离线，不调模型），点开看前 8 穗
- **0123 母题消长**：每个母题标「升起 +n」（近 60 天比之前 60 天多）/「冷下来了」/「近 60 天 n」
- **0124 跨媒介母题**：簇里同时有 ≥3 种类型（电影 + 音乐 + 图片…）标「跨媒介」
- **ROADMAP v0.39 星图**：口味页「展开星图」（点了才算、才画，不拖口味页）：同一份向量 PCA 到二维，近的挨着、远的离得远，母题名标在簇中心；拖动平移，滚轮或「放大 / 缩小 / 复位」缩放；点两颗星 →「嫁接这两颗」

把穗连起来
- **0104 作品实体**：同一部电影 / 专辑 / 书的几穗自动归成一部作品——标题里有《》按书名号，电影 / 音乐 / 摘抄按标题，作者不冲突才归（一边没写作者也算）。详情页「作品 · 《花样年华》（3 穗 · 1 根新枝）」列出同作品的其它穗；可以「归到别的作品…」「不归入」「按标题自动认」（手动的改动随同步）
- **0153 同曲不同平台**：作品名比之前先去掉（Live）/ - 2019 Remastered /【4K 修复】这类版本括号、全角半角、大小写和标点，网易云和 QQ 音乐的同一首歌归到一起
- **0105 穗间连线**：详情页「连线」：选关系（像 / 反着 / 引出 / 回应），搜标题点一下就连上；两头各存一条（存对方的 uid，换设备、导入导出都不断），对方那头显示「由它引出」「被回应」；可以拆
- **0120 被提到**：连线两头都看得到，作品工坊里用到这穗的作品也列在这里
- **0151 一起被嫁接过**：详情页「常和它一起被嫁接」：从新枝的素材里数共现次数，前 5 个，点「再接一次」用这一对去嫁接

顺带（体积）
- **动效库换成自写的**：Framer Motion（首屏约 42KB + 首屏后再加载 37KB）换成约 2KB 的 `components/rw/lite.ts`，只实现拾穗用到的进场 / 状态切换 / 退场（浏览器自带的 Element.animate），弹簧按阻尼换算成时长 + 缓出（不过冲）。和以前一样：首屏画完之前不播进场动画，减少动态效果时一律不动。首屏 JS 570 → 530KB（gzip 194 → 179KB），总资源 2223.5 → 2167KB，这一版的新功能全部装下还剩约 60KB（预算不放宽）

**性能**（docs/perf/v0.38.0.json，1000 穗，同一台测试机同一会话交替 9 轮 painted 中位数）：冷启动 v0.37 190ms → v0.38 195ms，4× 降速 575 → 586ms，Mann-Whitney 都不显著，持平（性能回归门 OK）。e2e 单跑：冷启动 189ms / 4× 503ms，搜索 ≤18.8ms，速记回车→卡片中位 9ms，滚动 60fps 无掉帧，备份 599ms。首屏 JS 570 → 530KB。

**已知问题 / 没有真机验证**
- 本机小模型是静态向量（词元向量取平均），只认得「意思大致相近」：短查询、比喻句、否定句会不准；配了 bge-m3 这类向量模型时它不参与
- 下载地址在发版 tag 公开之后才可用（jsDelivr 首次可能要等它从 GitHub 拉取）；国内网络下 jsDelivr / GitHub raw 都不通时下载会失败，没有别的镜像
- 星图没在真机上量过帧率（测试机 24 穗 / 单测 24 穗）；5 万穗时母题和星图只看最近 3000 穗
- 云端向量的语义搜索每次点「按意思再找找」都会把查询词发给向量接口（受「出站总开关」管）
- 自写动效没有弹簧过冲，个别按钮的弹跳感比以前弱一点
