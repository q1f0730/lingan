## 拾穗 · Glean v0.20.0 — 安全加固

这一版不加新玩法，专门补安全的窟窿：旧的安卓签名密钥公开在仓库里，任何人都能签出一个能覆盖安装的冒牌拾穗——现在换了新密钥，旧密钥作废；AI 密钥从明文的浏览器存储搬进系统钥匙串；界面开了内容安全策略（CSP），网络权限收紧；页面出错不再白屏，能自救、能复制诊断信息。

**下载**：安卓 `Glean_0.20.0_android.apk` · Windows `Glean_0.20.0_x64-setup.exe`（或 `.msi`）

**安卓升级：先试直接覆盖安装**
- 这一版起，APK 用新密钥签名，签名里带了一份「旧密钥 → 新密钥」的轮换证明（APK 签名方案 v3 密钥轮换）。Android 9 及以上的手机，理论上可以直接覆盖安装 v0.19，数据都在
- 万一安装时提示「签名不一致 / 与已安装的应用冲突」：先到 设置 → 备份与导入 → 导出备份，再卸载旧版、装新版、导入备份。只需要这一次
- 最低系统要求升到 **Android 9**（只出 v3 签名，CI 里不再用旧密钥）。Android 7 / 8 装不上这一版
- 装上 v0.20 之后，只用旧密钥签的冒牌包没法覆盖你手上的拾穗（轮换证明里不给旧密钥回退权限）
- 新证书 SHA-256：`97:71:C6:2B:20:A0:81:C6:C3:D1:7D:09:28:F2:31:4F:96:91:05:F1:CF:AA:8C:C1:AB:6B:FE:E4:CF:B3:6D:88`

**做了哪些（编号见 docs/ideas/ideas.csv）**
- **0708 签名密钥移出公开仓库并轮换**：生成新密钥（RSA 3072），keystore 和密码存进 GitHub Actions Secrets（`ANDROID_KEYSTORE_B64` / `ANDROID_KEYSTORE_PASSWORD`），发布流程从 Secrets 解码签名，签完立刻删掉临时文件，并核对签名证书指纹和轮换证明。仓库里删掉了 `signing/lingan.p12`，workflow 里不再有明文密码；仓库只留公开的轮换证明 `signing/glean.lineage`
- **0626 / 0617 AI 密钥进系统钥匙串**：Windows 存「凭据管理器」（Rust keyring），安卓存 Android Keystore（AES-256-GCM，密钥不可导出，本地只存密文）。第一次打开新版会自动把旧版存在本机的 key 搬进钥匙串，并从原来的设置里清掉；钥匙串万一写不进去，就保留旧做法，不会丢 key。网页版没有钥匙串，key 单独存在浏览器里（不和设置放一起），设置页会如实写明存在哪里
- **0627 内容安全策略 + 收紧网络权限**：脚本只允许 App 自带的，禁止插件、外嵌页面、外部表单；图片允许 data / blob / https（链接封面）；字体只用自带的。网络权限：https 仍然放开（链接解析要抓任意网页、「自定义」可以填任何 OpenAI 兼容服务）；http 只放本机和局域网（localhost、127.0.0.1、10.x、172.16–31.x、192.168.x、*.local），给 LM Studio / Ollama 这类本地模型用。公网的 http 链接解析时自动改走 https；接口地址填了公网 http 会提示「公网服务请用 https://」
- **0706 全局错误兜底**：整个界面和每个页面都有错误边界。某一页出错只显示「这一页出错了 · 重试 · 复制诊断信息」，导航和其他页照常能用；整个界面出错时可以「重试 / 重新载入 / 进安全模式 / 复制诊断信息」。未捕获的错误和 Promise 拒绝也都会记下来
- **0711 本地错误日志**：最近 100 条，只存在本机，不上传。只记时间、版本、页面、错误名和摘要；密钥、Bearer、长串、图片数据一律抹掉
- **0707 复制诊断信息**：设置 → 诊断。内容是版本、平台、WebView 版本、穗 / 新枝 / 图 / 套路条数、AI 是否已配置、密钥存放方式、存储是否持久、最近 20 条错误。不含密钥、不含穗的标题和内容
- **安全模式**：白屏或卡顿时用（错误页上或设置 → 诊断里开）。开着时不跑动效、缩略图、索引和预取，顶上有一条「安全模式 · 退出安全模式」
- **0625 数据库打不开时的兜底页**：升级迁移失败或存储损坏时不再白屏，显示错误摘要，可以「导出原始数据」（导出的文件能用「导入备份」导回去）和「复制诊断信息」
- **0629 备份 / 诊断 / 日志不含密钥**：加了测试，断言导出备份、诊断文本、错误日志里都没有 key
- **0604 申请持久存储**：首屏之后申请浏览器 / WebView 的持久存储，空间紧张时系统不清本库；诊断里显示状态

**质量**
- 新增单测 src/__tests__/security.test.ts（钥匙串迁移 / 失败回退 / 重置、安卓与钥匙串后端、脱敏、环形日志、诊断文本、CSP 与网络权限配置、链接 https 升级）
- e2e 新增 security()：带上和 App 同一份 CSP 跑示例 → 详情 → 搜索 → AI 嫁接 → 设置，全程 0 条 CSP 违规；旧版明文 key 自动迁移、AI 请求带的是迁移后的 key、改 key 只进钥匙串；口味页故意抛错只坏这一页；未处理的 Promise 拒绝进日志且脱敏；复制诊断不含 key；安全模式进出

**已知限制**
- 签名轮换只在 Android 9+ 生效；真机覆盖升级还没在实机上验证过，若失败按上面「先备份再卸载重装」处理
- 网页版（浏览器）没有系统钥匙串，key 仍在浏览器存储里（与设置分开、不进备份）
- https 没有收窄到固定域名：链接解析本来就要抓任意网页
- 旧密钥仍在 Git 历史里，已经作废，不再用于签名

**没变的**
- 数据库结构没变（还是 Dexie version 7），不需要迁移
- 视觉、嫁接、套路墙、秒搜、每日一穗都和 v0.19 一样
