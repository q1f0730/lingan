## 灵感暗房 v0.4.0 — 「哇」第一弹：ASCII 显影

**下载**：安卓 `Lingan_0.4.0_android.apk` · Windows `Lingan_0.4.0_x64-setup.exe`（或 `.msi`）

**新功能**
- 图片 ASCII 显影：卡片里的图片先是一层字符雾，再从画面中心向外一格格“显影”成真正的照片，每张图每次打开 App 只演一次，滚动时不会反复动
- 暗房空状态：一格底片从噪点里慢慢显出 ◉，循环播放
- 加载中改成 ASCII 小转圈；点「显影」按钮时，按钮上会散开一团字符雾
- 全部动效用画布增量绘制，不加依赖；系统开了「减少动态效果」时自动关闭，直接显示照片

**修复**
- 无
