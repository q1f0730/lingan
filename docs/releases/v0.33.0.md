## 拾穗 · Glean v0.33.0 — 系统入口：在别处一下就拾进来

这一版把拾穗接进系统的各个入口：电脑上选中别处的字按热键，小窗打开时已经填好；换一个热键选中就直接存成摘抄；剪贴板里是截图时小窗给一张缩略图「拾这张图」；资源管理器里右键「发送到 → 拾穗 Glean」；开机静默进托盘；热键可以改，被别的程序占了会直接告诉你。新增 `glean://` 链接：放进浏览器书签或快捷指令一点就拾，卡片菜单能复制某一穗的 `glean://item/…`，在别处点开就回到这一穗。验证码、像密码的一串不再被「剪贴板里有一穗」提示。

**下载**：安卓 `Glean_0.33.0_android.apk` · Windows `Glean_0.33.0_x64-setup.exe`（或 `.msi`）· Agent 桥 / 命令行 `glean-mcp.mjs` · 校验 `SHA256SUMS.txt`

**升级**：Windows 装着 v0.25 – v0.32 的会自动收到（更新前先自动备份）；安卓 v0.26 起可以在 设置 → 更新 里直接「下载并安装」。数据库不变（仍是 Dexie v12），不用迁移。「发送到」菜单要用 `setup.exe` 安装 / 升级一次才会出现（`.msi` 不装这一项）。

**做了哪些（编号见 docs/ideas/ideas.csv）**

电脑（Windows）
- **0004 带上选中的文字**：在任何程序里选中一段字按速记热键（默认 Ctrl+Shift+L），小窗打开时已经填好。做法是等你松开 Shift / Alt、替你按一次 Ctrl+C，读到新内容就拿走，再把剪贴板里原来的文字放回去；什么都没选中就是空的小窗。设置里可以关
- **0507 摘抄热键**：另设一个热键（默认关；比如 Ctrl+Shift+C，但它也是浏览器开发者工具的键），选中即存成一穗带「摘抄」标签，不弹窗
- **0515 热键可改 + 冲突检测**：设置 → 极速采集 点一下热键那一行、按下新组合就换；被别的程序占了、和另一个热键重复、或是 Ctrl+C / Alt+Tab / Win+L 这类系统常用键，都会直接说原因并退回原来的键
- **0003 剪贴板里的图**：唤出小窗时剪贴板里是截图（Win+Shift+S 之类），小窗直接给缩略图和「拾这张图」；同一张图只提示一次
- **0018 剪贴板守望跳过密码**：密码管理器 / 系统标了「不要记录」（ExcludeClipboardContentFromMonitorProcessing、CanIncludeInClipboardHistory = 0）的剪贴板内容不提示
- **0518 发送到 → 拾穗**：资源管理器里选中图片或 .txt / .md 文件，右键「发送到 → 拾穗 Glean」，一次最多 20 个，图片成图片穗、文字文件成文字穗
- **0516 / 0021 开机静默启动**：设置里一个开关（默认关），开了以后开机只进托盘不弹窗；网页在后台已经加载好，第一次按热键不用等冷启动
- **0517 单实例**：拾穗已经在托盘里时再双击图标 / 点 `glean://` 链接 / 用「发送到」，都交给已经在运行的那个，不会开出第二个
- **0520 外链交给系统**：穗里的网页链接交给系统默认程序打开，装了网易云、B 站这类 App 的会被它们接走（安卓同样走系统，只放行 http / https）

`glean://` 链接与手机
- **0510 glean:// 深链接**：`glean://capture?text=…&url=…&why=…&tags=a,b` 直接拾一穗；`glean://quick?text=…` 打开填好的速记小窗；`glean://item/<uid>` 打开某一穗（卡片右键 / 长按菜单「复制 glean:// 链接」）；`glean://graft?ids=<uid>,<uid>` 拿这几穗去嫁接；`glean://search?q=…` 秒搜；`glean://go/daily|library|settings|search` 去某一页。Windows 安装时注册，安卓在主界面上接；认不出的链接只提示一句、不做任何事
- **0506 长按图标加「搜索」**：长按拾穗图标多一个「搜索」（系统只允许 4 个的机型按顺序放前 4 个）
- **0514 安卓粘贴拾跳过敏感内容**：系统标了 IS_SENSITIVE（安卓 13+，密码管理器、验证码短信常用）或者一看就是验证码 / 密码的，「粘贴拾」不收，告诉你原因；主界面的「剪贴板里有一穗」也一样

顺带
- 系统主题跟随不再为一行调用加载 13KB 的窗口模块（直接调窗口插件命令），安装包总资源反而比 v0.32 小 2KB

**性能**：见下方 / docs/perf/v0.33.0.json。新代码全部懒加载（glean:// 路由 2.6KB、桌面入口 1.3KB + 2.2KB，设置面板进设置页的块）；首屏 JS 560.4KB（+2KB：深链接 / 速记小窗预填 / 剪贴板敏感判断的入口）。

**已知问题 / 没有真机验证**
- 选中文字靠模拟 Ctrl+C：在把 Ctrl+C 另作他用的程序里（比如终端）拿不到；VS Code 这类「没选中时复制整行」的编辑器会带上整行；剪贴板里原来是图片时只能放回文字（图片会被这次复制替换）
- 没在真机上跑过：Windows 上的热键改键 / 冲突提示、模拟 Ctrl+C 的时机、剪贴板图片读取、「发送到」快捷方式、开机静默启动、`glean://` 在浏览器里的放行弹窗；安卓长按图标第 5 项、IS_SENSITIVE 判断、`glean://` 在 vivo 浏览器里能否唤起。Rust 部分本地 Windows 目标 cargo check 通过、纯逻辑 cargo test 5 条通过；Kotlin 本地 kotlinc 编译通过；e2e 里用模拟的 Tauri 接口把前端整条路走通
- 「首次唤出 <150ms」没有真机数字，只做到了「开机后网页已在后台加载好」
