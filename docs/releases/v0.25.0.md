## 拾穗 · Glean v0.25.0 — Agent 与工程

这一版让拾穗能接进你的 AI 工具：Claude Code、Cherry Studio、Qoder 这类 Agent 可以搜你的穗、读你的口味、用你的套路墙查文字——默认只读，私密穗永远不给，写入要你在 App 里一次次点头。Windows 版从这一版起能自动更新，安卓会提示新版并引导下载。工程上，每次推送都跑质量门，首包体积有了预算，超了 CI 直接失败。

**下载**：安卓 `Glean_0.25.0_android.apk` · Windows `Glean_0.25.0_x64-setup.exe`（或 `.msi`）· Agent 桥 / 命令行 `glean-mcp.mjs` · 校验 `SHA256SUMS.txt`

**升级**：直接覆盖安装（安卓签名与 v0.20 起相同的新密钥 9771c62b… + 轮换证明）。数据库**不变（仍是 Dexie v10）**，没有迁移。Windows 用户这次还得手动装一次 v0.25.0，之后的版本会自己来。

**做了哪些（14 条，编号见 docs/ideas/ideas.csv）**

Agent 接入（E1）
- **0806 glean-mcp**：设置 → Agent 与 API 打开「本地 API」，拾穗在 `127.0.0.1:47321`（可改）提供 MCP（Streamable HTTP）和 REST。工具：`search_items` 搜穗、`get_item` 读穗、`list_branches` 列新枝、`get_taste` 口味侧写、`check_cliches` 查套路。Claude Code 一行命令接上，Cherry Studio 填 URL + 请求头或导入 JSON；只支持 stdio 的客户端用 Release 里的 `glean-mcp.mjs`（单文件、零依赖、Node 18+）。接入说明：docs/agent.md，设置页里的「复制命令 / 复制 JSON / 复制配置」会把令牌填好
- **0807 只读 + 写入确认**：默认只有读工具。设置里打开「允许 Agent 写入」后才多一个 `add_item`；每一次写入都把拾穗窗口叫到前面、弹窗写明谁要拾、拾什么，你点「允许」才收下，收下的穗进待理、来源标「Agent 代拾 · 客户端名」；拒绝或 3 分钟没点都算没同意
- **安全**：只听 127.0.0.1；Host 必须是本机（防 DNS 重绑定）；带浏览器 Origin 的请求一律 403（网页偷调不了）；Bearer 令牌常数时间比对，令牌存 Windows 凭据管理器，点「复制令牌」时才取，可一键更换；请求体上限 1MB。私密穗、墓碑、原图、向量都不返回
- **0809 口味资源**：MCP 资源 `glean://taste`（也是 `get_taste`）：高频标签、最近 30 天升温 / 冷下来、常拾的作者、「为什么」里的常用词、反口味、套路墙前 30 条——在 Claude 里写东西前让它先读
- **0836 套路墙当禁用词服务**：`check_cliches(text)` 返回撞到的说法和位置（内置禁用词 + 你的墙，划掉的不算，长词优先不重复报）；命令行 `node glean-mcp.mjs lint 草稿.md` 同样可用，撞了退出码 1
- **0834 glean 命令行**：`glean-mcp.mjs` 带参数就是命令行：`search / get / branches / taste / lint / add`，`--json` 输出 JSON
- **0838 Agent 访问审计**：每次调用记一行（客户端、工具、返回几穗、成没成），设置里「谁看过我的穗仓 · 近 7 天」按客户端汇总，下面是最近 8 次；不记查询词和穗的内容，只存本机（最多 300 条），可清空
- **0251**（B1 里重复的「MCP 服务」建议）随 0806 一起做掉

自动更新（C2 / D2）
- **0511 Windows 自动更新**：tauri-plugin-updater + GitHub Releases。CI 用更新私钥（只在 GitHub Secrets）给安装包签名并生成 `latest.json`，App 里的公钥校验签名，验不过不装。启动后空闲时检查，有新版就在后台下载好，提示「重启更新」，点了用安装器的静默模式装好再自动打开
- **安卓应用内检查新版**：读同一份 `latest.json`，有新版就提示，点「下载」用系统浏览器下新安装包（签名链不变，覆盖安装）。没有调系统安装器，所以不需要「安装未知应用」权限
- **0751 更新检查的隐私**：只 GET 一个公开静态文件（`releases/latest/download/latest.json`），不带任何设备参数；自动检查每天最多一次；设置 → 更新可以关掉，也能手动「检查更新」

工程（D2）
- **0704 CI**：新增 `.github/workflows/ci.yml`，每次推送 / PR 跑 `npm ci → tsc → oxlint → vitest → vite build → 体积预算 → glean-mcp 语法检查`，不发版；连续推送只保留最后一次
- **0742 体积预算**：`scripts/size-budget.mjs` 读 `dist/index.html` 算首屏真正加载的 JS / CSS，再看首片中文字体、最大的懒加载块和总量，预算在 `scripts/size-budget.json`，超了就失败；CI 上传完整的产物体积表（大 → 小、含 gzip）。现在的数：首屏 JS 540KB（gzip 181KB），预算 586KB / 195KB。建议表里写的「主 JS ≤350KB」现在做不到（v0.24 首屏就是 540KB），预算按当前值留约 8% 余量，之后只收紧
- **0712 质量门前置**：`release.yml` 新增 verify（tsc / vitest / build / 体积预算），全绿才建 Release
- **0714 npm ci**：所有 job 用 `npm ci` + npm 缓存；`package-lock.json` 这版起进仓库
- **0748 SHA256SUMS**：发版最后一步核对 apk / exe / msi / latest.json / 更新签名 / glean-mcp.mjs 都在，并上传 `SHA256SUMS.txt`。Windows 校验：`Get-FileHash .\Glean_0.25.0_x64-setup.exe -Algorithm SHA256`
- **0736 AGENTS.md**：给 Claude Code / Qoder / Codex 的仓库指南：目录、质量门、Dexie 迁移规则、密钥规则、视觉约束

**性能**（数字见 docs/perf/v0.25.0.json）
- 冷启动（InstaBox 同一会话交替测，1000 穗 / 300 图，中位数）：三轮共 33 次，v0.24 与 v0.25 没有可测差异——第三轮按 v0.24 / v0.25 / v0.24 排（A/B/A）：**v0.24 198 / 592ms（4× 降速）、v0.25 193 / 579ms、v0.24 再测 198 / 568ms**，v0.25 落在 v0.24 自己两次之间。网页 / 安卓冷启动路径只多一个立即返回的判断；本地 API 和更新检查都在启动 4 秒后、空闲时才加载
- 单独跑（e2e perf）：冷启动 184ms，4× 555ms；搜索 1000 穗断网最慢 17.6ms（4× ≤42ms）；网格 / 时间线 / 列表滚动 60fps 掉帧 0%（4× 也是）；备份 1000 穗 / 300 图（97.5MB）→ .glean 696ms，堆 +37.9MB，新设备导入 958ms
- 首屏 JS 540KB（gzip 181KB，比 v0.24 多 0.4KB），首屏 CSS 116KB

**没做 / 已知问题**
- 本地 API 只有 Windows 版：安卓和网页版没有能常驻的本机端口
- 拾穗主窗口要开着（缩在托盘也行）接口才应答；关掉 App 后 Agent 会收到「连不上拾穗」
- Agent 代拾的穗只收文字和链接，不收图片
- 安卓没有做应用内下载 + 调起安装器（0512 / 0732），只是引导到浏览器下载
- 更新前自动备份（0513 / 0750）、国内更新镜像（0548 / 0731）留到之后
- 没在真机上验证：Windows 自动更新的完整一轮（要等 v0.26 发出来才能从 v0.25 升）、Claude Code / Cherry Studio 真机连接（本版用 curl、模拟客户端和 stdio 桥测过协议）
