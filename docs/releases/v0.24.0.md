## 拾穗 · Glean v0.24.0 — 嫁接反馈与本地模型

这一版让嫁接「越用越像你」：不要的新枝可以顺手说一句为什么，下次它就避开；三根新枝不再撞车；可以钉住一穗当主干、标出讨厌的东西、贴几段自己的文字当语气样本。模型也可以换成你自己电脑上的 LM Studio / Ollama：不要密钥、断网能用、素材不出门，手机连同一个 Wi-Fi 也能用电脑上的模型。另外修了 v0.23 在低端机上冷启动变慢的问题。

**下载**：安卓 `Glean_0.24.0_android.apk` · Windows `Glean_0.24.0_x64-setup.exe`（或 `.msi`）

**升级**：直接覆盖安装（安卓签名与 v0.20 起相同的新密钥 9771c62b… + 轮换证明）。数据库升到 **Dexie v10**：只新增一张 `rejects` 表（不要的理由），不动任何旧数据。v1–v9 每一版的夹具库都有升级回归测试（本版新增 v9 夹具：待理、重复钥匙、来源 App、AI 新词原样保留）。.glean 备份多一种行 `{"t":"reject"}`，旧版本导入时会跳过它，不影响其它内容。

**做了哪些（10 条 + ROADMAP 1 项，编号见 docs/ideas/ideas.csv）**
- **0212 不要的理由**：点「不要」时，确认框里多一排可选理由——太俗 / 太远 / 做不了 / 不像我 / 自定义（一句话，40 字内）；不选也能删。选了的会记下来，最近 20 条写进下次嫁接提示词的 FEEDBACK 段（先汇总「太俗×3、太远×1」，再逐条列出那根新枝的标题和理由）。口味页新增「不要的理由」：每条能单独删（删了就不再参考），也能全部清空；撤销「不要」时理由一起撤回
- **0208 LM Studio / Ollama 一键探测**：设置 → AI 服务多了「本地模型（LM Studio / Ollama）」。点「探测本机」同时试 `127.0.0.1:1234`（LM Studio）和 `127.0.0.1:11434`（Ollama），读 `/v1/models`（Ollama 再退到 `/api/tags`），列出模型，点一下就用：自动填接口地址、对话模型，名字像多模态的填看图模型，有向量模型的顺手填上。不要密钥，「测试连接」照常可用。Windows 端没配 AI 时打开设置会自动探测一次本机
- **0209 局域网用电脑模型**：同一处填电脑的局域网地址（`192.168.1.23`、`my-pc.local`，端口可省），「探测这台电脑」。只接受本机 / 局域网地址（10.x、172.16–31.x、192.168.x、*.local），公网地址直接拒绝、不发请求。没探到时给出两家各自要做的事：LM Studio 打开「Serve on Local Network」；Ollama 设 `OLLAMA_HOST=0.0.0.0`、`OLLAMA_ORIGINS=*` 后重启。断网时顶栏改成「离线 · 本地模型照常嫁接」
- **ROADMAP 三枝不撞车**：三根新枝长出来后两两比相似度。配了向量模型就用向量余弦（三根不撞就只多调一次向量），没有就比字面（去掉素材名《…》和离线句式里固定的那几句后，按二元组算 Jaccard）。和前面留下的太像的那根，换成没用上的种子长的一根（变形法不和另外两根重复、也过套路墙），卡片上标「换掉了一根太像的」，结果顶上写换完后两两最多像到多少。阈值在设置里调：字面默认 45%（20–80%），向量默认 0.90（高级里，0.70–0.98）
- **0202 主干穗**：嫁接页已选的穗每行一个「钉住」，钉住的那穗是主干：提示词里标「主干」，要求每根新枝都以它为主体、其余穗只当养分；离线嫁接每根也都带上它。新枝的「因为这几穗」里主干加框加粗，新枝记下 anchorId
- **0203 为什么优先**：给模型的每件素材，块内先写「为什么打动我」，再画面，再作者 / 年份 / 内容；系统提示明说「为什么」比标题重要。已选的穗里有没写为什么的，嫁接页提示「补一句为什么，会让新枝更像你」，点名字直接去补
- **0206 反口味**：速记展开后多了「讨厌」：记成「我讨厌的」——不会被抽来当嫁接素材，嫁接时列进 AVOID 段（不带素材 ID，只当反面参照），口味统计也不算它。口味页「我讨厌的」列出来，点「不讨厌了」放回普通穗；卡片和详情上有「讨厌」小字
- **0210 我的文风**：口味页「我的文风」贴最多 3 段自己写的文字（每段 300 字），打开开关后嫁接提示词带上 STYLE 段，要求照这个语气写（只学语气和句子长短，不抄内容）
- **0234 去 AI 腔**：新枝写完后本地过一遍 40 条句式规则：「不仅…更是」「在…的同时」「与其说…不如说」改成直说，「值得一提的是」「总而言之」「不难发现」「在这个快节奏的时代」这类填充语删掉；《…》「…」里的原话不动。改了几处会在新枝上写「去 AI 腔 n 处」
- **0241 新颖度**：每根新枝标题下一行「很新 · 和旧枝最像 8%」/「有点眼熟 · 和旧枝最像 52%」——是和穗仓里所有已有新枝的最大字面相似度，越低越新；鼠标停上去能看到最像的是哪一根
- **0242 私密穗**：速记展开后多了「私密」。私密穗不会发给云端模型：嫁接（这组里有私密穗就改走离线，并提示）、看图打标签、向量、口味侧写都跳过它，用云端模型时也不会被抽来嫁接。用本地模型时，设置里可以勾「私密穗也可以发给本地模型」（只在接口是本机 / 局域网时生效）

**修复：v0.23 低端机冷启动变慢**
- 原因：穗仓第一次画出来之前，要把 1000 穗各扫好几遍（穗仓 / 待理数 / 缺为什么数 / 类型计数 / 示例数各一遍），还在首屏同步算标签云（每次排序都新建中文排序器）、「一周前 / 那年今天」（12 遍 × 全库日期运算）和今日一穗——这些都不在首屏上
- 改法：首屏要的计数合成一遍扫完；标签云、回顾、今日一穗等首屏画完、主线程空闲时再算；标签排序用一个缓存的排序器；回顾先按日期分一次桶再查 12 个目标日
- 结果（InstaBox 同一会话交替测，1000 穗 / 300 图，中位数）：见下方「性能」
