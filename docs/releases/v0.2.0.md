## 灵感暗房 v0.2.0 — 粘贴即收

**下载**：安卓 `Lingan_0.2.0_android.apk` · Windows `Lingan_0.2.0_x64-setup.exe`

**新功能**
- 收集时直接粘贴链接（或网易云 / QQ音乐 / 豆瓣的分享文字），自动读取标题、简介和封面，并识别是音乐、电影、图片还是普通链接
- 链接栏新增「识别」按钮
- 显影结果显示「来自你的底片」，每个创意都能追溯到素材
- 显影提示词加入禁用词表（沉浸式、旅程、交织、氛围感……），更不像 AI 腔

**修复**
- 文案卡片引号重复
- 口味画像「为什么」高频词过滤虚词；常客只显示出现 2 次以上的人
- 手机上显影按钮文字换行
