## 拾穗 · Glean v0.44.0 — 常驻得安静 · 配方跟着走

这一版让拾穗在电脑上「常驻」得更安静、更稳：窗口等首屏画好才亮出来，不再先闪一下白窗；开机自启只进托盘时，备份、同步这些后台活再晚一分钟，不和开机抢资源；第一次点叉关窗口，会用系统通知说一声「还在托盘里」（只说一次）；托盘菜单多了「从剪贴板拾」和「暂停剪贴板提示 1 小时」；按热键唤出时，窗口会出现在鼠标所在的那块屏幕上，大小和位置也记得住。真的崩了，下次打开会提示一句，原因记进 设置 → 诊断。安卓上设了上锁 PIN，最近任务里就不显示拾穗的画面。另外，嫁接配方和智能穗束现在跟着同步走了：手机存的配方，电脑上也能直接用。

**下载**：安卓 `Glean_0.44.0_android.apk` · Windows `Glean_0.44.0_x64-setup.exe`（或 `.msi`）· 浏览器扩展 `glean-extension.zip` · Agent 桥 / 命令行 `glean-mcp.mjs` · 校验 `SHA256SUMS.txt`

**升级**：Windows 装着 v0.25 – v0.43 的会自动收到（更新前先自动备份）；安卓 v0.26 起可以在 设置 → 更新 里直接「下载并安装」。数据库不变（仍是 Dexie v12），不用迁移。

**做了哪些（编号见 docs/ideas/ideas.csv）**

电脑常驻
- **0741 首屏画好再亮窗口**：窗口默认不显示，网页第一帧画完才亮出来（不再先闪白窗）；5 秒没等到就照常亮出来兜底
- **0563 开机自启后台活往后放**：开机自启（只进托盘）时，自动备份 / 同步 / 补链接 / 备份提醒整体再晚 60 秒；平常打开不变
- **0561 第一次关窗口提示还在托盘里**：第一次点叉，系统通知说一声「关掉窗口不会退出」，之后不再说
- **0538 托盘：从剪贴板拾 · 暂停剪贴板提示 1 小时**：「从剪贴板拾」带着剪贴板里的字打开速记；暂停期间速记条和小窗都不再提示剪贴板里的字和图，1 小时后自动恢复，也可以再点一次提前恢复
- **0562 唤出时跟着鼠标换屏**：窗口原本藏着 / 最小化时，按热键或点托盘图标，窗口挪到鼠标所在那块屏幕的正中；本来就在那块屏上就不动
- **0565 记住窗口大小和位置**：关掉再开、升级后，窗口回到上次的大小、位置、最大化状态（显示与否仍由拾穗自己管）

出问题时
- **0746 崩溃记录**：Rust 层崩溃时把原因和位置写进本机日志目录的 crash.txt；下次打开提示一次「上次拾穗意外退出了」，内容记进 设置 → 诊断 的错误日志（只在本机，不上传）
- **0747 正式版也写日志**：只记警告和错误，单个文件 256KB、只留一份旧的，在本机应用日志目录
- **0718 正式版编译优化**：整体 LTO、单代码生成单元、去掉调试符号（安装包更小、略快；崩溃位置仍能记下）

安卓
- **0567 最近任务里不显示画面**：设了上锁 PIN 就自动开（最近任务卡片一片空白，也不能截屏），设置 → 上锁 里可以单独开 / 关；没设 PIN 的照常

同步
- **嫁接配方 / 智能穗束进同步（v0.43 遗留）**：不改数据库，每台设备在同步文件夹里多一份加密的小文件；同名的取最后改的那一边，一边删了另一边也跟着删；没改过就不重传、不多列目录（回执里带一个指纹，别的设备看它变了才去下）。老版本设备不受影响，只是看不到

修复
- **速记条恢复草稿不再先闪空输入框**：上次没存的速记条 / 速记小窗草稿改在第一次画出来时就填好（v0.43 修过速记表单，这次是速记条，同样的问题）

瘦身（预算不放宽）
- 中文字体 6 片去掉竖排度量（vhea / vmtx）和基线表（BASE）——横排用不到，截图逐像素比 8 张 0 差，总资源少 3.4KB，腾给这一版

**还没真机验证**：首屏再亮窗口和 5 秒兜底、托盘菜单与第一次关窗口通知、多屏换屏和窗口记忆（都在 Windows 目标上编译检查过，界面部分用模拟 Tauri 的 e2e 测）；安卓最近任务隐藏（Kotlin 编译检查 + 模拟桥）。
