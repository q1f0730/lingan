## 拾穗 · Glean v0.15.0 — 搬去 Obsidian

*No lock-in.* 设置里新增「搬去 Obsidian」：把整个穗仓导出成 Markdown + 图片的 ZIP，解压后在 Obsidian 里「打开文件夹作为仓库」就能用。

**下载**：安卓 `Glean_0.15.0_android.apk` · Windows `Glean_0.15.0_x64-setup.exe`（或 `.msi`）

**新功能：导出为 Markdown（Obsidian 仓库）**
- 解压出来的结构：
  - `拾穗索引.md`：起点。按类型列出每一穗（作者 · 年份 · 拾于哪天），再列出全部新枝和它们的来源
  - `音乐/` `电影/` `图片/` `文案/` `链接/` `想法/`：每穗一篇笔记，按类型分文件夹
  - `新枝/`：每根新枝一篇笔记
  - `attachments/`：原图（不是缩略图），笔记里直接嵌入显示
  - `.obsidian/app.json`：以后在 Obsidian 里新贴的图也自动放进 attachments/
- 每穗笔记开头是 YAML 属性：类型、标题、作者、年份、标签（同时写一份 Obsidian 能认的 `tags`）、来源链接、记录时间（Obsidian 认得出的日期时间格式），有的话还有「为什么」；正文是摘抄 / 补充说明、为什么拾它、看图描述、来源链接，以及「长出的新枝」
- 新枝笔记：属性里的「来源穗」和正文「因为这几穗」都是 [[双链]]，点一下就到那一穗；还写着形式、用了什么变形、和另外两根哪里不同、20 分钟小实验、避开的套路、证据是否充分，并链到同一次嫁接的另外几根
- 链接一律带文件夹路径，同名的穗会自动编号（老的那穗保留原名），标题里的 `/ : ? # [ ] |` 等会断链或 Windows 不允许的字符会被换掉；包里不会留下点不开的链接：来源是没导出的示例或已删掉的穗时写成纯文字
- 示例穗默认不导出，勾上「包含示例穗」才带上（笔记里标着 示例: true）；只由示例长出来的新枝也随示例一起跳过
- 怎么拿到 ZIP：
  - **Windows**：弹出系统保存对话框，选好位置即可
  - **安卓**：两个按钮——「分享 ZIP…」走系统分享面板（发到网盘、微信、Obsidian 同步文件夹所在的 App 等）；「存到『下载』」直接存进手机的下载文件夹
- 文件名 `glean-obsidian-日期.zip`，中文路径在 Windows 资源管理器、安卓文件管理器和 unzip 里都能正确解开
- 只在本机打包，不上传任何东西；原来的 JSON「导出备份」保留不变，要在两台设备之间搬运数据还是用它

**测试**
- 单测 146 条（新增 14 条）：ZIP 读写往返（中文名、CRC、二进制）、文件名安全化与重名、YAML 头逐键核对、图片嵌入、新枝双链按引用顺序指回来源、示例默认排除 / 勾选后带上、从真实数据库（images 表原图）导出后解析整个包并检查**每一条双链都能落到真实文件**
- e2e 新增「搬去 Obsidian」：在界面上拾 3 穗 + 选一张真图、写入一根混合来源的新枝，点导出拿到下载的 ZIP 逐项解析：目录结构、每篇笔记的 YAML 键、图片字节、嵌入、双链全部可达、示例未导出；勾上「包含示例穗」再导一次核对；再模拟安卓原生桥，核对分块写入 + 系统分享 / 存到下载两条路径
