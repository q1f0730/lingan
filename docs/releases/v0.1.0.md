## 灵感暗房 v0.1.0 — 第一卷胶片

**下载**
- 安卓手机：`Lingan_0.1.0_android.apk`（首次安装需允许「安装未知来源应用」）
- Windows 电脑：`Lingan_0.1.0_x64-setup.exe`（推荐）或 `.msi`

**功能**
- 灵感库：收集音乐 / 电影 / 图片 / 文案 / 链接 / 想法，瀑布流胶片卡片，搜索、类型筛选、标签筛选
- 收集：一句「为什么打动我」，图片自动压缩
- 显影：从你自己的素材里按「跳跃度」抽取远距离底片强制碰撞，AI 先列套路再禁用，配合斜策略产出具体创意；今日底片；显影记录与收藏
- 没配 AI 也能用：离线显影
- 口味画像：母题、构成、年代、常客、7 天曲线 + AI 毒舌侧写
- 设置：智谱 GLM（免费）/ 硅基流动 / Gemini / 自定义 OpenAI 兼容接口；可选向量模型；浅色相纸 / 深色暗房；导入导出备份
- 数据全部保存在本机
