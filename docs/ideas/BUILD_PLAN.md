## 规则

- 选下一包：先所有 P0，再 P1、P2、P3；同优先级里按 影响高、成本低、和上一版代码区域相近 来凑主题。

- UI 走当前 main 的视觉；redesign/rewamp-ui 分支仍待用户点头，不合并。
- Dexie 改 schema 必加迁移；不删测试；key 不进文件/日志；署名 Q1f730。
