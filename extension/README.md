# 拾穗 · Glean 浏览器扩展（Chrome / Edge）

右键就能拾进本机的拾穗 App（v0.36 起）：

- **拾这一句**：选中文字右键。存成摘抄，链接带 `#:~:text=`，以后点开直接滚到原网页里的那一句。
- **拾这张图**：图片上右键。App 自己去下载原图（不受网页跨域限制），带上页面标题和链接。
- **拾这个链接 / 这个页面**。
- **拾当前时间点**：B 站、YouTube 视频页右键（或点工具栏图标）。记下视频链接 + 秒数（B 站 `?t=192`、YouTube `&t=192s`），能截到当前帧时把这一帧一起带上（桌面版从剪贴板取）；截不到只存时间码。

所有内容都拼成 `glean://capture?…` 交给本机 App（浏览器第一次会问「要打开拾穗吗」，勾「始终允许」）。扩展不联网、不存任何东西、不读你没点的页面。

## 安装

1. 在 Release 页下载 `glean-extension.zip` 并解压（或直接用源码里的 `extension/` 文件夹）。
2. Chrome 打开 `chrome://extensions`（Edge：`edge://extensions`），打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选解压出来的文件夹。

需要电脑上装了拾穗（Windows 版，v0.33 起注册了 `glean://`）。
